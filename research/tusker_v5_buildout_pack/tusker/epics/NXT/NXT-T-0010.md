# NXT-T-0010 · Rewrite SKILL, README, and repo guidance around the v5 model

## Intent

Make the public and in-repo guidance tell one story: tasks, not stories; docs as a close gate; repo-local canon through progressive disclosure.

## Scope

In:
- README language and examples
- SKILL.md rewrite
- reference file routing updates
- compatibility note for legacy commands and migration

Out:
- a full marketing-site redesign
- new screenshots or diagrams unless the text proves they are necessary

## Acceptance contract

| # | Outcome | Proof required | Docs impact |
|---|---|---|---|
| 1 | README stops presenting story/bug/D-note as the primary model. | README diff. | reference/skill, reference/cli |
| 2 | SKILL.md teaches the v5 contract, doc_nodes model, and docs gate. | SKILL diff and spot review. | reference/skill, reference/docs-pipeline |
| 3 | Guidance stays progressive instead of turning into one giant manual. | Review of routing and link structure. | reference/skill |
| 4 | Compatibility notes are explicit where old commands or note types still exist during transition. | README/SKILL compatibility section. | reference/cli, spec/migration-v5 |
