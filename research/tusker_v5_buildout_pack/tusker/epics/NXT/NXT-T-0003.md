# NXT-T-0003 · Replace templates, paths, bootstrap layout, and Obsidian-facing views

## Intent

Make a fresh Tusker bootstrap produce the v5 layout and template set instead of generating legacy story/bug/D-note structure.

## Scope

In:
- update bootstrap to create `_config/docs-map.yaml` and `_config/WORKFLOW.md`
- switch new work item creation to task-centric templates
- rename epic file layout to `epics/<ACR>/<ACR>.md`
- update dashboard/view assets to task language

Out:
- migrating existing repos
- rewriting the docs exporter logic
- fully redesigning the daemon

## Acceptance contract

| # | Outcome | Proof required | Docs impact |
|---|---|---|---|
| 1 | A fresh `tusker init` produces the v5 directory layout. | Bootstrap smoke test and generated tree snapshot. | reference/templates, reference/obsidian |
| 2 | New work items are created as tasks, not stories. | CLI or fixture output from create command. | reference/templates, reference/cli |
| 3 | The doc template is a durable page shape without work-lifecycle status. | Rendered doc template sample. | reference/templates, reference/docs-pipeline |
| 4 | Dashboard/views stop surfacing daemon-only runtime sludge as first-class user fields. | Updated view assets or snapshot output. | reference/obsidian, reference/runtime |
