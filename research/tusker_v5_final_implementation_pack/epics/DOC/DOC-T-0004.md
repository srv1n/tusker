# DOC-T-0004 · Implement docs impact hook with dry-run apply waive

## Outcome

Task closure runs explicit docs-impact workflow when doc_nodes are present.

## Acceptance contract

| AC | What must be true | Verification | Deliverables | Doc nodes |

| 1 | `tusker docs check <id>` dry-runs affected nodes, deltas, stale docs, proposed action. | CLI fixture | dry-run output | tusker/docs-system |
