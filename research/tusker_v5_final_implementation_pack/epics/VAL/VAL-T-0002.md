# VAL-T-0002 · Enforce docs impact unresolved at close

## Outcome

`tusker close` fails when a task has unresolved doc_nodes, knowledge deltas, or pending docs impact.

## Acceptance contract

| AC | What must be true | Verification | Deliverables | Doc nodes |
|---:|---|---|---|---|
| 1 | Task with doc_nodes and no update/waiver cannot close. | close fixture | failure output | tusker/tasks |
| 2 | Task with update event can close. | close fixture | pass output | tusker/tasks |
| 3 | Task with waiver event and reason can close. | close fixture | pass output | tusker/tasks |
| 4 | Task without doc_nodes does not require docs impact unless config requires it. | close fixture | pass output | tusker/tasks |

## Scope

### In

- Wire validator into close command.
- Recognize docs.updated/docs.waived events.
- Print unresolved nodes.

### Out

- Unrelated behavior changes outside this task.
- Broad refactors not needed to satisfy the acceptance contract.
- Marking the task done without evidence and docs impact resolution.
