# NXT-T-0002 · Introduce the v5 note model and parser support

## Intent

Teach Tusker to understand the new note model: `task` as the execution unit, `bug` as a task kind, and `doc` pages living under `tusker/docs/`.

## Scope

In:
- add v5 schema shapes for epic, task, and doc
- support `type: task` with `kind`
- support global doc pages under `tusker/docs/`
- keep legacy notes readable during the transition window

Out:
- moving existing files on disk
- rewriting the docs exporter
- changing the public help surface

## Acceptance contract

| # | Outcome | Proof required | Docs impact |
|---|---|---|---|
| 1 | The parser reads v5 epic, task, and doc pages without falling back to legacy assumptions. | Unit tests for parse + serialize round-trips. | spec/v5-overview, reference/templates |
| 2 | `task` is the canonical work type and `bug` is expressed through `kind: bug`. | Schema tests and new-note fixtures. | spec/v5-overview, reference/templates |
| 3 | Doc pages are discoverable from `tusker/docs/` and no longer require epic-local D-note paths. | Index discovery test over mixed epic/docs layout. | spec/migration-v5, reference/docs-pipeline |
| 4 | Legacy story/bug/doc notes remain readable long enough for migration to act on them. | Compatibility tests over legacy fixtures. | spec/migration-v5 |

## Constraints

- Do not silently coerce legacy notes into v5 semantics without the migration command or an explicit compatibility layer.
- Keep serializer output small and human-readable. The new schema should not repeat the old frontmatter sludge.

## Escalate if

- Any legacy field that looks disposable is actually consumed by the docs exporter or runtime.
- Doc-page discovery under `tusker/docs/` collides with another reserved path.

## Deliverables

- v5 schema constants and field ordering
- mixed-layout note discovery
- legacy compatibility tests

## Verification plan

- Round-trip a v5 epic/task/doc fixture through parse + serialize.
- Run mixed-fixture discovery over `epics/` plus `docs/`.
- Confirm a legacy story fixture still parses for the migration phase.
