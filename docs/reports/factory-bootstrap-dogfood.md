# Factory bootstrap disposable dogfood

The focused hermetic fixture follows the exact product flow: initialize a disposable Git repository, observe a stubbed local catalog, generate semantic profiles, author and validate a context-bound V2 plan, render review, dry-run import, import a held wave, preview routes, then audit authority and refs.

It proves lower-tier selection: routine work uses `execute-fast`/Luna; standard and complex work use Terra execution roles; review uses `review-independent`/Terra. The catalog contains Luna, Terra, Sol, and hidden `auto-review`; hidden inventory is never selected. Seven semantic profiles exist, with `execute-standard` as the project default and automation false throughout.

The V2 graph has four deterministic frontiers: `hello || goodbye`; `router`; `docs || e2e`; `integration-gate`. Doctor and dry-run pass at concurrency two. Review renders outcomes, proof, and frontiers, and Start is disabled because automation is off. The actual import creates only held/disarmed records.

The audit proves no runtime state, daemon authority, runs, attempts, release/spend activity, default-ref movement, or integration ref creation. It does not prove resident-daemon behavior or model execution; neither is authorized by this bootstrap slice. F1-F6 from the governing specification remain next-wave scope.
