# Fresh-agent fixture efficiency boundary

The fixture records process correctness, not synthetic efficiency. A fresh
agent and independent reviewer are separate live gates after the final pinned
candidate is available. The only comparable measurement allowed here is a
command-backed receipt from those actual runs; unknown provider usage remains
unknown and is never reported as zero.

The offline router scenarios intentionally do not emit usage claims. They
measure only refusal-before-start, deterministic import, recovery ownership,
review provenance, and closeout behavior.
