# Architect continuation

Completed or stalled material produces one report per objective and trigger revision. Duplicate triggers cannot create a second continuation. Reports retain accepted items, blockers, pending questions, and evidence. Applying a proposal or starting a wave remains subject to existing authorization, revision, stop, and spend controls.
