# TSK-G-0001 · Decide the dirty shared-checkout contract for work session start. Recommendation

## Why agent cannot do this

Both behaviors exist in committed code and tests; choosing which safety contract governs dirty shared checkouts is product intent that only the operator can set.

## Action

Decide the dirty shared-checkout contract for work session start. Recommendation: keep refusing with WORK_SESSION_UNSAFE_WORKSPACE for background/daemon runs and for interactive starts without --current-workspace; allow the dirty-path snapshot only for explicit --current-workspace interactive claims. Alternative: always snapshot and retire the refusal case.
