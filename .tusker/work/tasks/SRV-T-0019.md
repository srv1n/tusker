# SRV-T-0019 · Needs inbox cards open full task details

## Intent

Make every item in the Needs me inbox open the full task detail, not just show a review/failed-run card with action buttons. A human should be able to inspect intent, acceptance, verification, evidence, gates, and run history before accepting, sending back, redriving, or ignoring an item.

## Acceptance

| ID | Outcome | Proof |
|---|---|---|
| A1 | Clicking or keyboard-activating a Needs me item opens the canonical task detail for that task without losing the current review actions. | focused_test |
| A2 | The detail surface includes intent, acceptance, verification, evidence, gates, and run history from the existing task detail API. | focused_test |
| A3 | Returning to the Needs me list preserves the live inbox state and still allows Accept, Send back, or failed-run actions where applicable. | broad_test |

## Non-goals

- No task creation or frontmatter editing UI.
- No redesign of the underlying task markdown schema.
- No change to high-risk close policy.
