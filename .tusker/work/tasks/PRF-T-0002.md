# PRF-T-0002 · Prune dead registry projects and isolate test state roots

## Intent

The live registry (SQLite `projects` table under `~/Library/Application Support/tusker`, read via `RuntimeStore.ListProjects`, `cmd/tusker/runtime_store.go:891-910`; mirrored in `workspace.yaml`) holds 27 projects. Audited 2026-07-11: **12 are dead** — tracker_roots under `/var/folders/.../tmp.*` and deleted scratchpads — and one (`e2e`) points into a Claude session scratchpad. The 16 alive projects total ~2,750 markdown files, all scanned every poll tick (`daemon.go:429` → `project_loader.go:55`).

Root causes to fix, not just symptoms:
1. **Prune tooling**: add `tusker project prune` (or `project remove --dead`) that drops registry entries whose tracker_root no longer exists, plus the matching vault symlink mounts in the Obsidian vault (e.g. `rznapp-vault/tmp.*` dangling symlinks).
2. **Loader resilience**: `loadRegisteredProjects` should cheaply skip/flag missing tracker_roots instead of attempting them every tick.
3. **Test isolation**: e2e/smoke tests registered temp projects into the real state root. Tests must set `TUSKER_STATE_ROOT` (`cmd/tusker/daemon.go:53-61`) to a temp dir so `tmp.*` entries can never pollute the production store again.
