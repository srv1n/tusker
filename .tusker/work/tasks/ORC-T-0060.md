# ORC-T-0060 · Publish one relationship-complete execution graph

## Intent

CLI, Serve, and later operator surfaces consume the same stable graph projection for roots, managed attempts, retries, resumes, provider children, names, bindings, ownership, capability, and attention.

## Acceptance

| ID | Outcome | Proof |
|---|---|---|
| A1 | List and inspect support execution, root, parent, task, wave, source, provider, provider ID, agent type, binding, lifecycle, name, and attention filters with deterministic ordering and pagination. | See mapped verification. |
| A2 | The versioned projection returns typed nodes and edges, stable parent/root/task/wave links, provider ownership and capability facts, active/failed/attention child counts, and explicit partial visibility. | See mapped verification. |
| A3 | Existing runs and attempt consumers retain a compatibility projection while the CLI and Serve use one query implementation; retries and resumes never appear as concurrent managed children. | See mapped verification. |
| A4 | Graph reads, search, and the unbound inbox are deterministic and read-only and cannot attach work, mutate lifecycle, launch a model, claim a task, or change delivery authority. | See mapped verification. |
