## Intent
When a review sends a task back for changes, the next implementation attempt
should start on its own. Today the diagnosis says another attempt is
dispatchable, but the dispatch plan refuses because the previous run was
released, and asks for a new task revision. The operator had to requeue the
task by hand. The two views must agree, and a rework task must not need a
manual nudge.

## Failure and edge cases
- A run released for another reason (operator stop, retire, budget) must still
  refuse until the operator acts.
- A rework task must not get two attempts at once.
