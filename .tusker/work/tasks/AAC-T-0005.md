# AAC-T-0005 · Make agent access clear in the existing profile settings

## Intent

People can add an agent profile with sensible defaults, manage reference and private folders, and understand a missing control without learning provider flags. Done is before-and-after interface evidence plus interaction and accessibility findings. Saving settings never starts a model test.

## Implementation notes

Preserve the shared dirty baseline and reconcile current ownership before editing. Reuse existing profile, runner, runtime and UI authorities.
