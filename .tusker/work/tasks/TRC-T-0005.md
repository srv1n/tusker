# TRC-T-0005 · Rebuild daemon.db projections from the runtime journal

## Intent

Implement the second step from TRC-D-0001 after TRC-T-0004 lands: prove
`daemon.db` can be rebuilt as a projection from the runtime journal, then flip
the safest tables from authoritative writes to projected writes.

The rebuild path should create an empty runtime store, replay journal events
from `<state-root>/runs/<project_key>/<record_id>/`, and reproduce the live
projection for `runs`, `attempts`, `turns`, `supervisor_decisions`, and pending
approval/gate state. This is the test that prevents Tusker from keeping two
sources of truth.

## Acceptance

| ID | Outcome | Proof |
|---|---|---|
| A1 | A rebuild command or internal verifier can drop/recreate a test runtime store from runtime journals and produces equivalent `runs`, `attempts`, `turns`, `supervisor_decisions`, and pending approval/gate projections for fixture runs. | Inline verification |
| A2 | Live projection writes for `supervisor_decisions` and approval/gate state are derived from journal events rather than independent authoritative row writes. | Inline verification |
| A3 | Rebuild detects and reports corrupt, missing, duplicate, or out-of-order journal events with the first bad run/event named; it does not silently invent state. | Inline verification |
| A4 | Rebuild cost is measured on a synthetic fixture representing at least 30 days of tens-of-runs/day usage and remains acceptable for daemon startup or an operator repair command. | Inline verification |

## Non-goals

- No event-sourcing of `projects` or `daemon_settings`.
- No snapshot/compaction layer unless the measured rebuild cost proves it is needed.
- No user-facing serve UI changes beyond reading the rebuilt projections.

## Verification

| Covers | Check | Result | Notes |
|---|---|---|---|
| A1 | go test ./cmd/tusker -run 'RuntimeProjection.*Rebuild|DaemonDB.*Rebuild' -count=1 | pending | Empty store replay equals live projection. |
| A2 | go test ./cmd/tusker -run 'SupervisorDecision.*Projection|Approval.*Projection|Gate.*Projection' -count=1 | pending | First authority flip is covered. |
| A3 | go test ./cmd/tusker -run 'RuntimeJournal.*Corrupt|RuntimeJournal.*OutOfOrder' -count=1 | pending | Bad journals fail loudly. |
| A4 | go test ./cmd/tusker -run 'RuntimeProjection.*Cost|RuntimeJournal.*ThirtyDays' -count=1 | pending | Synthetic rebuild budget measured. |
