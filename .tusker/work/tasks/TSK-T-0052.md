interruptACPWrapperProcess and runProcessGroupAlive with durable fenced
per-job action intent. Use the prior tasks' projection and continuation path.

when viable, or Stop. Do not substitute SIGSTOP or change wave Pause.

only after exact-owner settlement. Start fresh explicitly creates a new
native session after settlement; preserve history, budgets and authority.

a signal. Late completion wins over attempted replay. Stop/continue races and
two-window actions cannot create a second owner. Add only supported adapter
capability handling, not a speculative generic control framework.
Proposed run_session_controls_test.go owns checks; update documentation.
