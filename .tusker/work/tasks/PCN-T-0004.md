## Intent
The operator must be able to see every process Tusker is running and stop any
of them, without opening Activity Monitor.

Add a Processes section to the existing Execution Operations page:
- One row per inventory entry: what it is (task or gate title, agent session or
  check), state (running, long-running, silent, stopping, stopped with reason),
  runtime and last sign of life as two separate clocks, owner link, PID and
  process group, and a Stop action.
- Stop stops the whole process group and records operator intent, so automatic
  retry does not restart it.
- Recently stopped processes stay listed with their reason for 24 hours.
- Project Settings gains the check silence limit and the agent silence flag.

## Failure and edge cases
- Stop on a process whose identity no longer matches shows a typed refusal and
  stops nothing.
- A long-running agent session that is still active is not shown as a problem.
- The page updates from the existing change stream, not a new polling loop.
