# ORC-T-0021 · Capture and deterministically classify red promotion evidence

## Intent

One structured failure packet lets Tusker distinguish infrastructure, known flakes, isolated task failures, and ambiguous integration failures without rediscovery.

| A3 | Deterministic rules classify known infrastructure, configured flakes, and isolated task failures before any model launch. | See mapped verification. |
| A4 | Infrastructure routes to bounded retry or infrastructure repair, a flake follows configured quarantine or rerun policy, and an isolated defect returns only the owning task and hard downstream closure to rework. | See mapped verification. |
| A5 | Repeated instances update one open repair contract per stable defect identity rather than creating unbounded duplicate tasks. | See mapped verification. |
