# MAC-T-0006 · Scaffold SwiftPM menu bar app (status item, app bundle build)

## Intent

Foundation for the Tusker Mac shell (epic MAC). The shell is a thin native wrapper around the serve UI: all state and logic stay in the Go daemon (`tusker serve`, default `http://127.0.0.1:7420`); the Mac app is chrome — menu bar presence now, floating panel / hotkey / notifications in follow-up tasks (MAC-T-0001..0005).

Build a SwiftPM-based AppKit menu bar app. No Xcode project — SwiftPM only, so agents can build and iterate headlessly.

- Location: `apps/mac/TuskerBar/` (new directory; `Package.swift` + `Sources/TuskerBar/`).
- Swift 5.10+, macOS 14+ deployment target, AppKit (`NSApplicationDelegate` lifecycle via a small `main.swift`, no storyboard/nib).
- Accessory app: `LSUIElement = true` in Info.plist (menu bar only, no dock icon by default).
- `NSStatusItem` with a template image (SF Symbol or bundled PDF template asset) so it adapts to light/dark menu bars.
- Status item menu (right-click or click for now): "Open Tusker" (opens the base URL in the default browser via `NSWorkspace.shared.open`), separator, "Quit TuskerBar" (⌘Q). Base URL hardcoded to `http://127.0.0.1:7420` for this task; MAC-T-0002 makes it configurable.
- App bundle build: a `scripts/build-app.sh` (or equivalent) that assembles `TuskerBar.app` from the SwiftPM release binary + `Info.plist` + icon placeholder, then codesigns — Developer ID identity if one is present in the keychain, ad-hoc (`codesign -s -`) otherwise. Expose as `make mac-app` in the repo `Makefile`.
- Critical constraint to preserve: `UNUserNotificationCenter` (MAC-T-0003) only works from a signed `.app` bundle launched as a bundle — never from a bare `swift run` binary. The bundle path must be the primary way to run the app from day one.
- `apps/mac/TuskerBar/README.md`: layout, build commands, how to run, the thin-shell rule (no business logic in Swift; talk to the daemon HTTP API only), and the bundle/signing constraint above.

Keep the Go module untouched: no changes outside `apps/mac/` and the `Makefile`.
