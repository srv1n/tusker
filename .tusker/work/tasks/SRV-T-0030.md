# SRV-T-0030 · Search task IDs and open actionable task detail

## Intent

Let a human jump from any control-room screen to an exact task contract by typing a task ID, without first finding the project or work-board column. Reuse the canonical task detail so review, acceptance, gate, and other human actions remain available in one place.

## Acceptance

| ID | Outcome | Proof |
|---|---|---|
| A1 | A global search surface opens from the sidebar, mobile shell, and Command-K, searches registered projects by task ID, and displays unambiguous project-aware results. | Focused UI tests |
| A2 | The project overview exposes the same search surface without creating a second search implementation. | Focused UI tests |
| A3 | Choosing a result opens the canonical task contract, where existing human actions remain available; keyboard and empty/error states are usable. | Focused UI tests and typecheck |

## Non-goals

- Full-text search across task prose, docs, evidence, or event logs.
- A second task detail route or duplicated human-action controls inside search results.
- Server-side ranking until the registered-project task volume proves client-side lookup insufficient.
