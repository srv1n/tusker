# SGC-T-0003 · Warn on scratch size in doctor and document the retention contract

## Intent

- What this is: the health-check command warns when a project's scratch area
  grows past a sane budget — two hundred megabytes by default — and offers a
  one-command repair that runs the same cleanup as the sweep command. The
  written guidance for agents is updated to state plainly that scratch
  expires and anything durable must be promoted to evidence.
- Why it matters: agents park gigabytes of intermediate files in scratch
  because nothing ever told them it expires. The warning catches runaway
  projects; the documented contract changes agent behavior so the warning
  rarely fires.
- What "done" looks like: the health check on a bloated project shows a
  scratch-size warning with a repair, running the repair reclaims the space,
  and the installed guidance that agents read now states the retention rules.

## Acceptance
