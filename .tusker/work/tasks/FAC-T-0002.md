# FAC-T-0002 · Show which work happened outside the daemon on the board and web view

## Intent

The board people read and the web dashboard are supposed to reflect reality.
Right now neither can show that a person ran a piece of work by hand in a live
session — every lane looks automated. Once the work itself remembers it was
picked up by hand, the views that people look at should say so plainly.

This task surfaces the hand-run marker everywhere a person looks: the text board
the team scans and the web dashboard. A lane that was picked up by hand is
labelled as hand-run; automated lanes stay unlabelled or read as automated.

Done looks like: open the board or the web view and a hand-run lane is visibly
marked as such, side by side with automated lanes that are not — no more
pretending everything came off the automated line.

## Acceptance

| ID | Outcome | Proof |
|---|---|---|
| A1 | The text board shows a clear hand-run label on lanes that were picked up by hand. | Inline verification |
| A2 | The web dashboard shows the same hand-run label on those lanes. | Manual proof (before/after screenshot) |
| A3 | Lanes the automated line handed out are not mislabelled as hand-run. | Inline verification |

## Non-goals

- No new marker is invented here; this reads the hand-run marker the claim step already records.
- No change to what counts as hand-run — only its display.
- No history/timeline view of past hand-run work; only the current live lanes.
- No board layout redesign beyond adding the one label.

## Implementation notes

Best-guess file map — verify before editing:

- `renderStreamBoard` and `streamRow` in `cmd/tusker/streams.go` build the
  `# Streams` markdown table; read the hand-run marker (from FAC-T-0001) and add
  a label/column or fold it into the `Status` cell.
- The serve backend builds run rows in `cmd/tusker/serve_command.go`; expose the
  marker on the run payload.
- Web view: `internal/serve/ui/src/features/runs` (`ProjectRuns.tsx`, `board/`)
  and `features/overview` render the lanes; add the label there.
- Keep the word plain ("hand-run" or "outside daemon"), matching FAC-T-0001.
