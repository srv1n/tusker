# LIF-T-0004 · Add run heartbeats, interruption detection, and safe reclaim

## Intent

Make run liveness explicit and recoverable. Active harness integrations heartbeat through the canonical ownership service; reconcile classifies stale claims as interrupted after a configurable grace period, records why, and permits safe reclaim without erasing the original attempt.

## Acceptance

| ID | Outcome | Proof |
|---|---|---|
| A1 | Claimed and running records carry lease expiry and last-heartbeat timestamps derived from an injectable clock; heartbeats are idempotent and rejected for terminal or foreign-owned runs. | focused_test |
| A2 | Missing start acknowledgement and expired running heartbeats transition to distinct interrupted outcomes with bounded, operator-readable reasons. | focused_test |
| A3 | Reconcile cannot classify a stale row as currently running; stale claims release task/project capacity and can be reclaimed exactly once without losing prior attempt history. | focused_test |
| A4 | Runner completion racing heartbeat expiry has deterministic transactional semantics and never produces two terminal outcomes or two live owners. | focused_test |
| A5 | Daemon restart reconstructs liveness from persisted leases/session metadata and does not revive dead processes merely because a row once said held. | broad_test |

## Non-goals

- Do not infer liveness solely from task status or historical attempt outcome.
- Do not keep interrupted runs active indefinitely for manual cleanup.
- Do not require a human gate to reclaim an expired run.
