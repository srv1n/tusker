# RUN-T-0003 · Document the runner seam for future harnesses

## Intent

Future harnesses (Pi Mono, OpenCode, others) should be addable without archaeology. Write the runner-adapter contract as a spec: the Runner interface (Start/Resume/Reconcile/Interrupt/Collect), required capabilities and how optional ones degrade, the attempt event schema and machine final-status contract, session/lease lifecycle, workspace expectations, and how profiles (RUN-T-0002) map onto a new harness's flags. Include a conformance checklist and point at the existing fake-runner test harness as the acceptance bar for any new adapter.
