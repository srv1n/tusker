## Intent
Every seeded demo task asks for code and tests but owns only one output file,
so a real agent either breaks ownership or cannot meet its contract. On
2026-10-19 the standalone smoke task went to review twice and was sent back
both times for this conflict. Each demo task must own the files its outcome
asks for, without overlapping its siblings, so a real run can pass review.

## Failure and edge cases
- Parallel tasks in one wave folder must not own each other's files.
- The offline timer lane and its exact fixture content stay unchanged.
