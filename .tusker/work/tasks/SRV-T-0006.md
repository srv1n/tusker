# SRV-T-0006 · Make delivery path entry work in TuskerBar

## Intent

- What this is: Make ordinary text editing work inside the Tusker Mac app and
  give Delivery review a calm starting state.
- Why it matters: A user cannot review a delivery if they cannot paste its path,
  and an error shown before they act makes a healthy setup look broken.
- What "done" looks like: Standard Mac editing shortcuts work in Tusker text
  fields, and Delivery waits for a real plan path before attempting a review.

## Acceptance

| ID | Outcome | Proof |
|---|---|---|
| A1 | TuskerBar exposes the standard Undo, Redo, Cut, Copy, Paste, and Select All commands with normal macOS shortcuts, so focused fields in the embedded app receive them through the responder chain. | Automated test |
| A2 | Opening Delivery with no selected plan shows guidance instead of immediately reporting that a hard-coded plan does not exist; typing or pasting a repository-relative path and choosing Review performs the normal review. | Automated test |

## Non-goals

- Discovering, ranking, or editing runner/model profiles.
- Automatically choosing among multiple delivery plans.
