# DEL-T-0003 · Drain armed wave DAG frontiers across task, review, retry, and dependency boundaries

## Intent

Teach the resident daemon to treat an armed wave as a durable desired outcome,
not a one-shot dispatch request. It must continuously drain each runnable DAG
frontier across implementation, proof, review, rework, restart, and landing
boundaries until the wave completes or only bounded parked closures remain.

## Acceptance

| ID | Outcome | Proof |
|---|---|---|
| A1 | Given a serial/parallel fixture DAG, the scheduler dispatches the complete eligible frontier up to the configured cap and automatically advances later frontiers as dependencies become machine-green. | Deterministic scheduler timeline test. |
| A2 | Proof-satisfied soft dependencies, review requests, reviewer close, ordinary task boundaries, and clean worker exits do not stop wave draining or require operator input. | Lifecycle matrix covers implementation → review → done and soft-edge flow. |
| A3 | A retryable machine failure retries within policy; an exhausted task parks only itself and its hard dependency closure; a genuine human gate blocks only its affected closure; independent branches continue. | Failure-injection matrix with exact dispatched/parked sets. |
| A4 | Every modifying task uses an isolated attributable workspace/branch, returns a diff or artifact plus acceptance-mapped focused proof, and cannot absorb dirty source-repo changes or edit another task. | Workspace/delivery guard tests. |
| A5 | Proof-complete branches enter the serialized wave landing lane; merged-state validation uses cached fingerprints, optimistic batching, and bisect-on-red so green members still land. | Integration-lane tests cover semantic conflict and isolated failure. |
| A6 | Daemon restart reconstructs armed-wave desired state, adopts or reclaims live work safely, and resumes draining without duplicate claims or repeated authorization. | Crash/restart e2e fixture. |
| A7 | Queue/status/digest output distinguishes runnable, running, review, landed, machine-parked, human-blocked, and stale-authorization members without calling touched code complete. | Golden queue and timeline output. |

## Non-goals

- Letting one worker implement multiple task contracts.
- Infinite retries or whole-wave failure because one branch is red.
- Direct writes or merges to the default branch.

## Operator artifact

A deterministic execution timeline for a fixture DAG showing serial and
parallel frontiers, one injected machine failure, one human-gated branch,
continued independent work, restart recovery, review, and landing.
