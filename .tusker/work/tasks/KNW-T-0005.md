# KNW-T-0005 · Init scaffolds the documentation system

## Intent

- What this is: setting up Tusker in any repository now creates the whole
  documentation system on day zero — the reference-docs folder with an
  overview page carrying the header contract, the spec and decision-log
  folders, and the spec-session skill — and the installed skills teach every
  agent the two habits: search before reading or writing documentation, and
  never create a document except through the create command.
- Why it matters: the system we built in this repository exists only because
  a human demanded it mid-flight. It must exist by default, everywhere,
  without anyone hammering an agent for it.
- What "done" looks like: initializing a fresh repository and immediately
  running validation and the map command both succeed; the overview stub is
  on the map; the installed skill text contains the search-first and
  create-through-the-command rules.

## Acceptance

| ID | Outcome | Proof |
|---|---|---|
| A1 | Init on a fresh repo creates the docs folder with an overview stub (valid header, root of the tree), the specs and decisions folders, and installs the spec skill. | Inline verification |
| A2 | The freshly initialized repo passes validation and generates a map with no manual edits. | Inline verification |
| A3 | Init on a repo that already has the structure changes nothing and says so (idempotent). | Inline verification |
| A4 | The tusker and spec skills state the search-first and create-through-command habits as hard rules. | Inline verification |

## Non-goals

- No legacy-doc triage (KNW-T-0006 owns brownfield adoption).

## Implementation notes

- File map (best guess): extend the existing init path (locate via
  `grep -rn "func.*Init\|\"init\"" cmd/tusker/cli.go cmd/tusker/commands_create.go`);
  scaffold templates as embedded strings or `embed.FS` next to the init code;
  skill text updates in `skills/` (tusker skill) and the spec skill template
  installed to `.claude/skills/spec/SKILL.md`.
- Overview stub: `docs/system/00-overview.md` with `subject: overview`,
  `status: canonical`, no `part_of` (root), a front-matter contract comment,
  and an empty generated-region fence so `docs map` has a target.
- Reuse the relative-symlink skill install behavior (commit 8b9426f) rather
  than copying files.
