# MAC-T-0005 · App Intents for Shortcuts/Spotlight/Raycast (stretch)

## Intent

Stretch polish: expose TuskerBar's navigation verbs to the OS automation layer so Spotlight, the Shortcuts app, and Raycast (via Shortcuts) can drive it without the mouse. Builds on deep links (MAC-T-0004) — every intent is a thin wrapper over the same internal routing.

Using the App Intents framework (macOS 14+ target already set):

- `TogglePanelIntent` — "Toggle Tusker Panel".
- `OpenReviewQueueIntent` — "Open Tusker Review Queue": summons the panel at the review queue path (same path convention as SRV-T-0024 deep links).
- `OpenTaskIntent` — "Open Tusker Task" with a required `taskID` string parameter: summons the panel at that task's deep link.
- Register them as `AppShortcutsProvider` phrases ("open tusker review queue", "toggle tusker panel") so they appear in Spotlight and Shortcuts without user setup.
- Intents must route through the existing `PanelController`/deep-link code path — no duplicated navigation logic.

- No Siri phrase tuning beyond the default App Shortcuts registration; no widgets (separate task if ever).
