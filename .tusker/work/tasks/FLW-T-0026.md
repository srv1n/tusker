# FLW-T-0026 · Keep the complete documentation and instruction chain authoritative

## Intent

Define the ownership chain for root bootstrap instructions, installed operator skill, project skill/canon, product specs, decisions, runbooks and evidence. Each meaning has one owning source and conditional links; shipped/generated copies expose provenance and update safely without overwriting user-owned instructions. Token objective: Measure the full bootstrap-to-canon route including tool calls; avoid both giant manuals and tiny-file fetch chains.
