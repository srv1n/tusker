## Contract
Wire explicit native Continue and Recover from saved context through existing
admission and recovery. Verified seams: resumeCapability, resolveResumeSession,
incompatibleResumeSessionReason, resumeContextFingerprintMismatch,
queueOutcomeUnknownRecovery, ACPRunner.Resume and CodexExecRunner.Resume.
TSK-T-0032 supplies authoritative unknown-outcome eligibility; consume it.
Native continue retains native session ID but records a new attempt of the
same job. Unsupported/expired sessions refuse, never silently start fresh.
Context recovery is explicit and records a different session plus provenance,
retained public history, task state, checkpoint and unresolved operation.
Before retry reconcile effects using process/provider receipts, outputs and
relevant Git state. Unknown external effects need a specific operator choice;
accepted completed operations must not be replayed. Keep current authority,
material/workspace identity, budgets and proof fences.
Duplicate requests from two windows, lost responses, capacity waits and daemon
restart must retain one correct parent/child and at most one worker.
Proposed run_session_continue_test.go owns checks; document semantics.
