# LIF-T-0002 · Make registered repository the default runner workspace

## Intent

Make the registered repository path the default working directory for new Codex and Claude runs. Persist an explicit project workspace policy with `shared` as the default and `worktree` as opt-in. Preserve logical project identity independently from the physical workspace so optional worktree sessions still appear under the registered project.

## Acceptance

| ID | Outcome | Proof |
|---|---|---|
| A1 | New and existing projects without an explicit workspace policy resolve to `shared` and launch runners with the registered repository as cwd; no hidden worktree is created. | focused_test |
| A2 | Projects can explicitly select `worktree`; those runs receive an isolated checkout while retaining project id, registered repository path, and physical workspace as separate fields. | focused_test |
| A3 | Shared mode defaults modifying-run concurrency to one per project, persists an explicit override, and rejects a launch beyond the configured limit before a runner process starts. | focused_test |
| A4 | Codex and Claude runner launch tests assert the exact cwd for both workspace modes, including paths containing spaces and `~` normalization at the boundary. | focused_test |
| A5 | Existing worktree cleanup/reconcile behavior remains intact for projects that opt in. | broad_test |

## Non-goals

- Do not implement file-level conflict detection or automatic merging.
- Do not silently migrate an explicitly configured worktree project to shared mode.
- Do not use session history location as the source of project identity.
