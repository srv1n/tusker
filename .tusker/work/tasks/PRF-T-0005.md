# PRF-T-0005 · Cache git HEAD and reduce per-run ps execs in poll tick

## Intent

Idle ticks spawn **zero** subprocesses (confirmed — the syspolicyd/exec load correlates with active runs, not idle polling). But each active run costs ~5 execs per tick:

- 1 × `git rev-parse HEAD` per reconciled active run per tick, uncached, against the main repo root: `reconcileRun` → `recordRunBoundaryTraces` (`daemon.go:1586` → `trace.go:150-159`) → `resolveTraceCodeSHA` (`trace.go:477`). HEAD rarely changes mid-run; re-shelling every 5s is pure waste and the dominant recurring git spawn.
- 2 × `ps` (`-o stat=`, `-o lstart=`) in `reconcileRun:1783` via `processIdentityMatches` (`daemon.go:4620, 4656, 4670`), then **2 more** for the same runs in the end-of-tick sentinel liveness pass (`daemon.go:930-937` → `sentinel.go:326-364`).
- Review completion tick adds 4 more one-shot git calls (status ×2, diff --stat ×2: `daemon.go:3278, 3977, 4003-4007`) — rare, acceptable.
- No git library anywhere; all `exec.Command("git", ...)`. No auto-commits from the poll path. The observed `tusker validate --json` child is agent-driven (reviewer prompt checklist), not daemon-scheduled.

Deliverables: cache the HEAD SHA per repoRoot keyed on `.git/HEAD` (and resolved ref file / `packed-refs`) mtime, invalidating on change; share one `processIdentityMatches` result per run per tick between reconcile and the sentinel instead of duplicate `ps` pairs; keep the `syscall.Kill(pid,0)` fast path as the primary liveness check.

## Acceptance

| ID | Outcome | Proof |
|---|---|---|
| A1 | A tick with an active run and unchanged HEAD spawns zero git subprocesses. | Inline verification |
| A2 | At most one ps identity probe (2 execs) per active run per tick, shared between reconcile and sentinel. | Inline verification |
| A3 | Trace code SHA is still correct immediately after a real HEAD change (cache invalidates on ref mtime). | Inline verification |

## Non-goals

- Review-packet git calls on completion ticks (rare, keep).
- Dispatch-time worktree operations.
