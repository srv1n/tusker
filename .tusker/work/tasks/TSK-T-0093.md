## Intent
`HumanActionCard` returns early for question and permission items before calling its hooks, so a mounted card whose item changes kind crashes React. Interrupt eligibility (`isInterruptibleRun`) and Redrive's disabled state are still computed in the browser, against the spec's "the UI never guesses". The Say result "duplicate" is not shown. The run-state UI test only greps component source. Eight UI tests started failing in 834e84a4 (list in shared_context).

## Verified seams
- HumanActionCard.tsx: early returns for `question` and `permission` (~35-36) before `useGateAction`, `useTaskStatusAction`, `useConfirm` (~37-39).
- runs/detail/helpers.ts `isInterruptibleRun` (~28); RunHeader.tsx Redrive disabled logic; RunSayBox.tsx result display.
- tests/run-state-say.test.ts (source-text assertions).

## Implementation contract
Locked:
- Split HumanActionCard into `QuestionActionCard`, `PermissionActionCard` and `GateActionCard` components selected by a hook-free wrapper.
- Interrupt and Redrive availability come from server capabilities (run-controls-parity adds `interrupt`). Delete `isInterruptibleRun`.
- Say results show accepted, duplicate (with the existing delivery) and refused (with the server reason).
- Replace the source-grep test with rendered tests that mock the API per state (Working, Waiting on you, Quiet, Blocked, Failed, Lost, Stopped, Queued, Finished) and assert the buttons shown equal the capabilities returned.
- For each of the 8 regressed tests, decide whether the test or the UI is wrong, citing the commit that changed the behavior. Fix the UI when it lost a contract behavior; update the test only when the UI change was intended and say why in the test. Do not change the 5 baseline failures (gate-green owns them).
- Rebuild the bundled UI (`bun run build`) so internal/serve/ui/dist matches the source.

## Failure and edge cases
- Needs item changes from gate to question while mounted → no crash.
- Server says interrupt unavailable on a Working run (e.g., review lane) → no Interrupt button.
- Say returns duplicate → UI shows "Already sent" with the original delivery state.

## Ownership and coordination
Hard-depends on run-controls-parity (capabilities) and run-state-truth (state values). Owns only UI files listed; `internal/serve/ui/test/` ownership covers only the 8 regressed test files.
