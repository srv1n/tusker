# CLN-T-0006 · Adopt the 1000-line code-file guideline with an advisory check

## Intent

Agents lose grip on files past roughly 1,000 lines, and Tusker's own sources are the worst offenders (`commands_v7.go` ~3.5k, `daemon.go` ~3.3k). The guideline text is already in `skill/references/ENGINEERING_DISCIPLINE.md` (Operating Posture). This task propagates and enforces it: add the guideline to the repo-contract policy docs (`docs/ai-contribution-policy.md` and its `skill/assets/repo-contract` source) so it ships to adopting repos, and add an advisory (non-fatal) check to `make check` that lists code files over 1,000 lines against an allowlist seeded with the current god-files.

## Acceptance

| ID | Outcome | Proof |
|---|---|---|
| A1 | The 1,000-line guideline (with the deliberate-exception clause) appears in the skill discipline reference and both copies of the AI contribution policy. | Inline verification |
| A2 | `make check` emits an advisory section listing code files >1,000 lines not on the allowlist; it does not fail the build. | Inline verification |
| A3 | The allowlist is seeded with current oversized files and references CLN-T-0007 as the burn-down task. | Inline verification |

## Non-goals

- No file splitting in this task (CLN-T-0007 owns the burn-down).
- No hard-fail enforcement.
