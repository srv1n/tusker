# ACO-T-0005 · Return wave results to the architect and continue the objective

## Intent

The architect receives an accurate completed or stalled wave report and can propose the next work without the operator relaying it. Configured automatic continuation can run the next valid wave, and pause or stop retains pending work. Done is a two-wave behavior matrix with duplicate and restart evidence. Scope is successive-wave continuation within the agreed objective.
