## Intent
Run records from projects that are no longer registered kept counting toward
the machine-wide run limit. Four retry-queued runs from demo projects deleted
in September held every slot, so nothing new could start, and nothing showed
why. Runs whose project is not registered must not hold capacity, and removing
a project must be safe to preview and must refuse an unknown project.

## Failure and edge cases
- A registered but disabled project keeps its runs counted as today.
- Removing a project that does not exist reports that and changes nothing.
- A preview of a removal lists what would be deleted and deletes nothing.
