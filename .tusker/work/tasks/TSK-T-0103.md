## Intent
`docs status` prints "N commits since <stamp>" but never calls a doc
stale, and a legacy date-only `last_verified` reads as "never
verified" with no hint to re-stamp. Make staleness an explicit flag.

## Verified seams
- `DocsFreshness` in `internal/docgraph/freshness.go` already computes
  `TouchingCommits` against the commit in `last_verified` via
  `countTouchingCommits`. Add `Stale bool` to `FreshnessRecord`:
  true when `TouchingCommits > 0`.
- `docsStatusCmd` in `cmd/tusker/docs_cmd.go`: add `"stale"` to JSON
  rows, print `STALE` in text output, add `--stale` to list only stale
  docs, and exit nonzero with `--stale --strict` when any doc is stale.

## Edge and failure cases
- Date-only stamp: `never_verified` stays true; text output says
  "date-only stamp, run tusker docs verify <subject>".
- Stamp commit no longer exists (rebased away): treat as never verified,
  as today.
- Doc with no `describes`: not stale, and text output says "no
  describes".
