# SRV-T-0027 · Dogfood human-action review flow in the Mac panel

## Intent

Dogfood the completed human-action flow in the actual compact Serve panel and
the TuskerBar host, using the existing `MAC-T-0001` / `MAC-G-0002` manual
verification gate as the golden case. This task proves that the new contract is
not merely a well-tested desktop page: a human can open the product, understand
the required action quickly, record the result, and see the task update.

## Acceptance

| ID | Outcome | Proof |
|---|---|---|
| A1 | With `MAC-G-0002` open, the 420×640 Serve panel leads with a single manual-verification action whose wording matches the gate's action and completion condition. It visibly explains why a human is needed and lists only A1, A2, A3, A4, and A6 as the review checklist. | manual_check |
| A2 | The primary review path is understandable without Tusker vocabulary: a human can complete the listed checks, submit a concise result, and see the gate/task refresh. `Clarify`, raw gate ids, evidence kinds, actor fields, and generic Satisfy/Waive/Obsolete controls are not required to finish. | manual_check |
| A3 | Returning the task to rework from that surface asks for a reason and produces the normal rework state; no stale human-action card remains after either completion or rework. | manual_check |
| A4 | The live `tusker serve` API—not fixtures or client-side inference—drives the card in both the full task page and `/panel?shell=1`. The UI remains readable with no horizontal overflow at 420×640. | focused_test |
| A5 | The signed TuskerBar app hosts the compact panel without changing panel lifetime, focus, navigation, or daemon-start behavior owned by the MAC tasks. | manual_check |

## Non-goals

- Do not alter the V7 gate persistence schema, the Mac panel shell behavior,
  or unrelated Serve views except for defects required to make the shared
  human-action flow work end to end.
- Do not satisfy or waive `MAC-G-0002` merely to make a test green; record the
  actual observed result and return to rework if a covered behavior fails.
