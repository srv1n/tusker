# AGX-T-0004 · Instrument token cost per attempt and set packet budgets

## Intent

Token economy should be a measured, first-class signal, not an impression. The runtime already captures per-attempt token usage in review packets; extend it so cost is queryable and budgeted: (1) per-task and per-epic cumulative token rollups exposed via CLI `--json` and shown in review packets; (2) packet word/token size recorded at emission time; (3) advisory budgets configurable in `tusker.yaml` (packet size by task size s/m/l, attempt token ceilings), with warnings surfaced in daemon logs and review packets when exceeded. This data feeds later model routing (cost per accepted task by runner/model).

## Acceptance

| ID | Outcome | Proof |
|---|---|---|
| A1 | Cumulative token usage per task (across attempts and lanes) is queryable via a CLI command with `--json` and appears in the review packet. | Inline verification |
| A2 | Packet emission records its own size, and packets exceeding the budget for the task size produce a visible warning. | Inline verification |
| A3 | Budgets are configurable in `tusker.yaml` with sensible defaults; unset config keeps current behavior plus defaults. | Inline verification |

## Non-goals

- No model routing decisions in this task (measurement only).
- No hard failures on budget overrun; advisory only.
