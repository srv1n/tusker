# MAC-T-0008 · Index projects and tasks in macOS Spotlight

## Intent

Make Tusker projects and tasks discoverable in macOS Spotlight. Searching a
project name, task ID, or task title must produce a result that opens the
native Tusker window at the selected project or task.

## Acceptance

| ID | Outcome | Proof |
|---|---|---|
| A1 | Projects and tasks are indexed with stable project-qualified identities and useful title, subtitle, description, and keyword metadata. | focused_test |
| A2 | Selecting a Spotlight project or task result opens the native Tusker window at the corresponding project or task route. | focused_test |
| A3 | The index refreshes at app launch and after stream events, and stale Tusker entries are removed without affecting other Spotlight domains. | focused_test |
| A4 | Existing deep-link and App Intent behavior remains intact. | broad_test |

## Non-goals

- Replacing the existing in-app task search or floating panel.
- Indexing private task body contents beyond the title and operator-facing metadata.
