# MAC-T-0001 · Floating panel: non-activating NSPanel hosting WKWebView of serve UI

## Intent

Add the floating panel to the TuskerBar scaffold (MAC-T-0006, `apps/mac/TuskerBar/`). This is the core interaction: click the status item (or, after MAC-T-0002, press the hotkey) and a floating web panel appears over whatever you're doing.

- An `NSPanel` with `.nonactivatingPanel` style, `level = .floating`, `collectionBehavior = [.canJoinAllSpaces, .fullScreenAuxiliary]` — it must appear over full-screen apps and on every Space without stealing focus from the frontmost app until the user interacts with it.
- Hosts a single long-lived `WKWebView` loading `<baseURL>/panel?shell=1` (base URL `http://127.0.0.1:7420` until MAC-T-0002 makes it configurable). The webview is created once and kept alive while the panel is hidden — reopening must not reload the page. Set `customUserAgent` to append ` TuskerShell/<app version>` (SRV-T-0023 detects this). Enable `isInspectable` so the web content can be debugged from Safari.
- Left-click on the status item toggles the panel, positioned directly under the status item (multi-display aware: use the status item button's window screen). Right-click keeps the existing menu; move "Open Tusker" there if needed.
- Default size 420×640, user-resizable; last size persisted in `UserDefaults` and restored.
- Dismissal: Escape key and clicking outside the panel both hide it (hide, never close/destroy).
- Daemon-unreachable state: if the page fails to load (connection refused, etc.), swap in a native placeholder view — "Tusker daemon isn't reachable" with a Retry button and the hint `tusker serve`. Retry with backoff automatically while the panel is visible; swap back to the webview on success.
- The SRV-T-0023 `/panel` route may not exist yet when this task runs; a plain serve UI page (or the placeholder for a 404) is acceptable for manual checks — the shell must not depend on the route's content, only on the URL convention.

Structure the code so the panel controller is one focused type (e.g. `PanelController`) that MAC-T-0002 (hotkey toggle) and MAC-T-0003/0004 (deep-link navigation: `show(path:)`) can call without rework.

## Non-goals

- No global hotkey, settings, or configurable base URL (MAC-T-0002).
- No notifications, badge, SSE (MAC-T-0003); no `tusker://` scheme or JS bridge beyond the user agent (MAC-T-0004).
- No changes to the serve UI (SRV-T-0023 owns `/panel`).
