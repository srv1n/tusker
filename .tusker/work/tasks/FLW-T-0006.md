# FLW-T-0006 · Make state revisions, reconciliation and snapshot invalidation reliable

## Intent

Stale body edits fail compare-and-swap; successful mutations recompute revisions under lock and publish exactly the state actually saved. Token objective: Prevents repeat reads, unnecessary refresh events and recovery loops.

## Acceptance

| ID | Outcome | Proof |
|---|---|---|
| A1 | Stale body edits fail compare-and-swap; successful mutations recompute revisions under lock and publish exactly the state actually saved. | See mapped verification. |
| A2 | Targeted reconciliation changes only the selected record; dry-run reports stale terminal records without writes; stale attempts repair once; identical refresh emits no event and changed snapshots do. | See mapped verification. |
| A3 | Interrupted writes and competing mutations preserve the last committed state, fail visibly and recover idempotently; no unrelated task or user file is lost. | See mapped verification. |
