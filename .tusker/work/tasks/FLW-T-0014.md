# FLW-T-0014 · Define useful visual, performance, backend and migration proof

## Intent

Visual changes require comparable before/after views; new UI needs an after view plus stated absence of a baseline. Performance proof includes before/after workload, units, method, environment and revision. Token objective: Small typed summaries link to full evidence; avoid screenshot/log dumps in every agent context.
