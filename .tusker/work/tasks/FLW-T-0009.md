# FLW-T-0009 · Accept conversational human decisions with verifiable authority

## Intent

Use one authority rule for every human-owned gate. An agent actor or arbitrary human: string cannot satisfy a human decision, including generic signoff gates. Token objective: Settled decisions are reused at their exact scope; genuine new material still requires a new answer.
