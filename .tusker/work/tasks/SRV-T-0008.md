# SRV-T-0008 · Rewire Serve UI to the Tusker v2 reference

## Intent

Write a few plain sentences a former product manager can read cold — no file
names, symbols, or commands here; those live in the appendix below.

- What this is: A complete visual and interaction rewrite of the Serve app using the supplied Tusker v2 reference.
- Why it matters: The current interface exposes implementation machinery before product outcomes and does not match the approved layout.
- What "done" looks like: Every referenced screen uses the new editorial shell, derives operational state from real served data, and keeps unsupported actions visibly unavailable rather than simulating them.

- No removal of technical compatibility routes that existing deep links use.
