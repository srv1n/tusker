# AGX-T-0001 · Regroup the CLI surface for one-hop command discovery

## Intent

The CLI exposes ~40 top-level commands; a fresh agent running bare `tusker` gets 100+ lines of help and burns tokens paging to the command it needs (observed in live sessions). Regroup around the agent loop: bare `tusker` and `tusker --help` show a compact help of the 8–10 loop commands (`next`, `automation plan`, `packet`, `claim`, `verify add`, `finish`, `show`, `status`, `feedback add`) grouped by loop stage, with one pointer line to `tusker help --all`. Move rare setup/operator commands under a grouped section or an `admin` umbrella. Record before/after help token counts.

## Acceptance

| ID | Outcome | Proof |
|---|---|---|
| A1 | Bare `tusker` and `tusker --help` emit at most 40 lines focused on agent-loop commands, with a pointer to the full surface. | Inline verification |
| A2 | Every existing command remains reachable and `tusker help --all` lists the full tree; the surface guard is updated intentionally. | Inline verification |
| A3 | Default help word count is reduced by at least 60% versus baseline (recorded before/after). | Inline verification |

## Non-goals

- No command removals or renames in this task (CLN-T-0003/CLN-T-0004 own removals).
- No behavior changes to the commands themselves.
