# AGX-T-0005 · Capsule frontmatter: one-glance triage under a token budget

## Intent

Agents should be able to decide whether a file is worth opening from its frontmatter alone. Add a `capsule` frontmatter block — `what` (one line: what this is and does), `use_when`, `skip_when` — to knowledge docs, domain INDEX/CANON pages, specs, project skill, and epics (optional on tasks, where title plus Intent already serve). Enforce a token budget: default 80 tokens total for the capsule block (configurable in tusker.yaml validation settings), validator warns over budget and fails at twice the budget. The writing agent pays this cost once so every future reader saves a full file read. Surface capsules everywhere bulk triage happens: `tusker list --json`, `search` results, `show --capsule`, and packets must include the capsules of routed doc/domain files so an agent picks its reading list without opening anything.
