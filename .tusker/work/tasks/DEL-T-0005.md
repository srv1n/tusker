# DEL-T-0005 · Render artifact-first wave briefs for delivered, parked, and human-blocked outcomes

## Intent

Make the morning output answer "what did I get?" before "what did the
orchestrator do?" Normalize each task's best compact artifact, assemble it by
acceptance outcome, and show precise distinctions between implemented, proven,
reviewed, landed, documented, parked, and genuinely human-blocked work.

## Acceptance

| ID | Outcome | Proof |
|---|---|---|
| A1 | Tasks can declare and validate an operator artifact contract for UI, performance, backend/API, reliability, security, refactor, and documentation work without requiring raw artifacts in task markdown. | Schema/validation fixture matrix. |
| A2 | `wave brief` and JSON render sections in this order: Outcome, See it, Landed, Rework/parked, Human action, Documentation. Empty sections are concise and machine-readable. | Golden CLI/JSON tests. |
| A3 | Artifact cards tie screenshots, videos, benchmark deltas, traces/replays, matrices, security notes, diff summaries, and knowledge links to acceptance IDs and durable evidence refs. | Artifact normalization tests. |
| A4 | The brief never equates code touched with complete; it exposes implementation, proof, review, landing, and documentation states separately and names the first actionable failure. | Honesty fixture tests based on partial multi-ticket output. |
| A5 | Serve and Mac morning surfaces consume the same contract, prioritize visual/performance artifacts, and provide task/wave/gate deep links without dumping logs, transcripts, or token counts. | UI contract tests and screenshot fixture. |
| A6 | Human action contains only valid gates with one exact action and resume ID; ordinary review/test failures stay under Rework/parked. | Gate classification tests. |

## Non-goals

- Replacing task proof or reviewer decisions with a pretty summary.
- Storing raw logs, transcripts, or large binaries in task bodies.
- Requiring screenshots for work where a benchmark, trace, matrix, or concise diff summary is more truthful.

## Operator artifact

A rendered fixture brief containing a UI recording, before/after benchmark,
backend trace, security note, landed summary, machine failure, and one genuine
credential gate.
