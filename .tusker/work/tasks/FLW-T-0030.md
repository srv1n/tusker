# FLW-T-0030 · Deliver reusable installed-harness execution and conformance

## Intent

An operator registers an installed agent, tests its supported permissions through one repeatable conformance flow, and executes a task with an honest verified result. Compatible harnesses require configuration only; novel command-line dialects require a small isolated adapter. Implement the canonical spec including its ordered slices, module contract, failure matrix, and current-system documentation update.

| ID | Outcome | Proof |

| A2 | A broken or non-executable first PATH candidate does not hide a later healthy candidate, which is pinned for the attempt. | See mapped verification. |
| A3 | If no candidate is healthy, the run remains unclaimed and reports the checked candidates plus the first actionable error. | See mapped verification. |
