# SRV-T-0018 · Serve UI review-loop hardening: real actions + irreversible-action safety + mock-leak purge + batch review

## Intent

An Opus UX audit + direct code verification found that SRV-T-0017's "full parity — real
write/action control surface" claim overshot what was actually wired. The API seam is real
(`internal/serve/ui/src/lib/api.ts` `USE_MOCK=false`; every endpoint exists server-side), but
the review-critical UI does not call the real mutations. Verified defects (file:line):

- **Fake inbox actions (P0):** `components/needs/NeedCard.tsx:56-59` — `resolve()` is
  `setTimeout(setGone)` with zero API calls; Accept & close / Approve / Retry / Resume / Send
  answer all animate away and do nothing server-side, then reappear on refetch.
- **Dead primary CTA (P0):** `features/docs/TaskContract.tsx:184-188` — the prominent
  "Accept & close" is a TODO no-op; only a buried rail "Accept" is real.
- **Mock leaks into live views (P0):** `features/docs/LibraryList.tsx:19` merges `localDocList`
  fixtures into the live index; `TaskContract.tsx:68/84/93` fall back to `localTaskDetails` /
  `localDocContents` / fixture-generated review checklist on any live miss.
- **Suppressed honesty badge (P0):** `components/Sidebar.tsx:104` gates the "fixture data"
  badge on `USE_MOCK`, so it hides while the leaks above serve fixtures.
- **No confirmation on irreversible ops (P0):** land / wave-land / gate-waive / gate-obsolete /
  daemon-stop fire on a single click (`TaskContract.tsx`, `features/ops/ProjectOps.tsx`).
- **Swallowed mutation errors (P0):** `lib/queries.ts` mutations use only `onSettled`; failed
  land/close/gate/daemon actions surface nothing (blank result line).
- **One-at-a-time review, no batch (P1):** `features/work/WorkTable.tsx` / `WorkBoard.tsx` rows
  are plain links; no multi-select / bulk accept-land for wave-boundary review.
- **Dead affordances (P1):** J/K keyboard advertised but no handler (`GlobalInbox.tsx`,
  `ProjectNeeds.tsx`); evidence items are no-op buttons (`TaskContract.tsx:615`); hardcoded
  evidence `covers:"A1"` and boilerplate feedback payloads.

This is the operator's dogfood review gate; as-is it silently fakes approvals. Fix is pure
front-end (all endpoints exist). Executed as a 4-runner parallel front-end pass with disjoint
file ownership and one central `bun` gate.
