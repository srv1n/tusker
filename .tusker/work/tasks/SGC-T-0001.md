# SGC-T-0001 · Reap task scratch on every close route

## Intent

- What this is: when a task is closed or discarded, its scratch folder is
  deleted in the same motion — no matter whether a human closed it or the
  background daemon did.
- Why it matters: scratch folders currently live forever, and a week of agent
  work can leave close to a gigabyte of dead intermediate files per project.
  Today the automated close path does not even remove the plan file that the
  manual path removes.
- What "done" looks like: close a task by hand or let the daemon close one,
  and its scratch folder is gone afterward. The one exception: a task whose
  accepted evidence deliberately links into its own scratch keeps that folder
  at close.

## Acceptance

| ID | Outcome | Proof |
|---|---|---|
| A1 | Manually closing a task deletes its entire scratch directory, not just the plan file. | See mapped verification. |
| A2 | Discarding a task and the daemon's automated close both delete the task's scratch directory through the same shared cleanup. | See mapped verification. |
| A3 | A task with link-only evidence pointing into its own scratch keeps that scratch directory at close. | See mapped verification. |

## Non-goals

- Age-based sweeping of non-task scratch entries (SGC-T-0002).
- Doctor warnings or documentation of the retention contract (SGC-T-0003).

## Implementation notes

2026-08-04 read and may have drifted.

- Broaden `removeTaskPlanFile` (`cmd/tusker/daemon.go:6191`) into a
  task-scratch reaper that removes `scratch/<TASK-ID>/` entirely, subject to
  the link-only exception. Keep one deletion engine — SGC-T-0002's sweep will

- Call sites to cover: manual close `cmd/tusker/v7_control_cmd.go:406`,
  discard `cmd/tusker/v7_discard_cmd.go:277`, and the automated close in
  `cmd/tusker/completion_reactor.go:2135` which today calls nothing.
  Confirmed 2026-08-04: hooking the shared projection
  `applyV7TaskCloseProjection` is NOT viable — its signature is

  no vault path or task ID. Wire each of the three routes explicitly.
- Link-only detection: evidence records with `artifact_durability:
  "link_only"` whose recorded path resolves under `scratch/<TASK-ID>/`
  (recording happens near `cmd/tusker/v7_evidence_attempt_cmd.go:212-219`).
- Name new tests with the substring `ScratchReap` (e.g.
  `TestScratchReapOnManualClose`, `TestScratchReapOnReactorClose`,
