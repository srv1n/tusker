# WUX-T-0015 · Preserve project pins, recent order and return locations

## Intent

People can keep frequent projects at the front and return to their exact work without projects jumping around on each click. Done is a tested preference migration and a concise behavior report. Scope is saved navigation and restoration; visual shell changes belong to the next task.
