# CLN-T-0002 · Consolidate to a single vault: fold legacy tusker/ tree into .tusker/

## Intent

Two vaults coexist: the legacy root `tusker/` tree (V5/V6-era: ~49 tasks, 6 epics, domains, dashboards, plus WORKFLOW.md/CHEATSHEET.md that still teach the forbidden `active` status vocabulary) and the live `.tusker/` vault. Exactly one vault should remain. Triage the legacy tree: anything still worth doing becomes a V7 task in `.tusker/work`; still-true canon moves into `.tusker/knowledge/domains`; everything else is archived under `research/legacy/` or deleted. Record the triage list (migrated vs dropped IDs, with one-line reasons) as evidence before deleting.
