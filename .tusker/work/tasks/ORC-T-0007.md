# ORC-T-0007 · Surface branch age and divergence in automation plan

## Intent

Doctrine sets a 48-hour branch defect line, and the rzn backend accumulated a
38-branch unmergeable fleet before anyone noticed. Age and divergence are
cheap git facts; surface them where dispatch decisions are made. When a task's
workspace exists and is a git worktree, `tusker automation plan` includes
branch name, branch age (hours since it diverged from the default branch), and
ahead/behind counts; past a configurable threshold the plan carries a warning
note. The stream board (ORC-T-0002) reuses the same fields.

## Acceptance

| ID | Outcome | Proof |
|---|---|---|
| A1 | Plan JSON includes branch, branch_age_hours, and ahead/behind versus the default branch whenever the task workspace is a git worktree. | Inline verification |
| A2 | Past the configured age threshold the plan includes a distinct warning entry; the threshold defaults to 48h and is vault-configurable. | Inline verification |
| A3 | Tasks with no workspace or a non-git workspace omit the fields without error. | Inline verification |
