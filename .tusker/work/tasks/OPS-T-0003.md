# OPS-T-0003 · Escalation ladder and the morning digest

## Intent

Binding design: `docs/design/prior-art-playbook.md` §5 decision 6 (donors: Gas Town escalation/`gt prime`, Google TAP revert culture; observability lesson: "6 PRs merged and I had no idea when"). For unattended operation the human must be **on-call by exception + batch reviewer by ritual**, which requires two mechanisms the ledger lacks: a severity-routed escalation record, and a single morning surface.

Semantics:

1. **Escalation record** (`kind: escalation`): created by the daemon (sentinel violation, circuit-open, park, crash-loop) or by a runner via `tusker escalate -s <P0|P1|P2> --task <id> "<desc>"`. Severity routing: P2 = recorded, appears in digest; P1 = recorded + macOS user notification (osascript, config-off-able); P0 = recorded + notification + a distinct persistent red banner in serve. Runners may escalate only for: system errors, security concerns, unresolvable conflicts, stuck-loop self-reports — the contract text says so.
2. **Stale re-escalation:** unacknowledged escalations past a threshold (default 4h) bump severity one level once; `tusker escalate ack <id>` stops it. Acks are recorded with actor.
3. **`tusker digest`** renders the morning surface, in order: (a) open escalations by severity, (b) landed since last digest (waves + tasks, from wave audit trails), (c) red/parked with the failing gate one-liner and redrive hint, (d) pending hard gate (high/critical tasks in review awaiting human acceptance), (e) budget/circuit status. Also exposed at `/api/digest` for the UI; `--since` overrides the window; digest render marks the watermark.
4. Everything is derived from existing records (runs, waves, escalations, parks) — the digest stores only its watermark.

## Non-goals

- No email/SMS integration (macOS notification only; channels are config points for later).
- No auto-remediation from escalations (they route attention, nothing else).
- No UI implementation beyond the banner flag and digest endpoint (UI consumes them separately).
