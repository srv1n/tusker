## Intent
The operator skill (`skills/tusker/`) does not tell agents to record a
user ruling, or to check a doc's freshness before quoting it.

## Change
Add two short rules to `skills/tusker/references/KNOWLEDGE.md` (move to
`SPECS.md` only if that is where decision docs are already covered):
1. When the user rules on a question, write or update the decision doc
   in the same session (`tusker docs new <subject> --kind decision`,
   or `--supersedes <old>` once that flag exists).
2. Before quoting a doc as fact about the code, read its
   `code_conformance` and run `tusker docs status --stale` (or check
   its `describes` paths for changes since `last_verified`). If it is
   stale, drift, or unverified, say so when quoting it.
Keep each rule to one or two sentences; follow the existing style of
the file. Do not add new sections elsewhere in the skill.
