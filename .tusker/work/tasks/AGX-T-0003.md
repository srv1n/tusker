# AGX-T-0003 · Cap changelog and knowledge-delta churn by risk tier

## Intent

In adopting repos, per-change changelog/knowledge-delta expectations caused agents to write voluminous documentation updates on every edit, slowing implementation and burning tokens well beyond the value produced (observed cross-repo; see the feedback digests). Make documentation churn risk-gated by default: low/medium-risk tasks with no `doc_nodes` default to `Knowledge delta: none expected` and must trigger no validator nags for absent changelog/doc updates; high/critical keep the mandatory delta. Enforce a hard line budget on knowledge-delta entries consistent with existing body budgets, and route repeated lessons into domain canon via explicit `feedback promote` instead of per-task appends.

Also set a terse style contract for agent-authored proof surfaces (evidence cards, attempt summaries, verification notes): telegraphic, factual, command + PASS/FAIL, no narrative filler. Contracts and specs stay in full prose (ambiguity there is expensive); it is the proof chatter that gets compressed. Runtime JSONL logs are exempt — they are plumbing, not model input.

## Acceptance

| ID | Outcome | Proof |
|---|---|---|
| A1 | Validation emits no knowledge-delta or docs warnings for low/medium tasks without `doc_nodes` (regression test). | Inline verification |
| A2 | Knowledge-delta sections exceeding the configured line budget warn, and fail past the hard cap. | Inline verification |
| A3 | Skill references instruct agents: no changelog/doc updates unless the contract names `doc_nodes`; repeated lessons go through `feedback promote`. | Inline verification |
| A4 | The originating cross-repo friction is linked as evidence (feedback digest reference). | Evidence card |
| A5 | Skill references define the terse proof style (telegraphic evidence/attempt summaries; contracts stay full prose). | Inline verification |

## Non-goals

- No weakening of the high/critical knowledge-delta requirement.
- No removal of the docs close-gate mechanism for tasks that explicitly declare `doc_nodes`.
