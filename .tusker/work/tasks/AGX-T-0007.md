# AGX-T-0007 · Reserve human approvals for capability and artifact acceptance

## Intent

Keep human attention for capability, authority, and explicitly subjective artifact acceptance. Agents and reviewer lanes must not turn implementation choices already settled by an approved task/spec into fresh approval questions.

## Acceptance

| ID | Outcome | Proof |
|---|---|---|
| A1 | The canonical Tusker skill gives agents an explicit, fail-closed human-approval boundary and treats approved task/spec decisions as already decided. | focused_test |
| A2 | Gate creation/validation rejects decision or signoff gates that merely ask a human to approve implementation work such as an already-specified legacy mapping removal. | focused_test |
| A3 | Genuine human-only gates remain valid for credentials, inaccessible environments, authority decisions, and explicitly subjective screenshots, recordings, or final artifacts. | focused_test |
| A4 | Generated runner/reviewer guidance does not convert risk-tier close policy into ad hoc implementation approval questions. | broad_test |
