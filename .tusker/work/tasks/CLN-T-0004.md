# CLN-T-0004 · Remove version branding from the user-facing surface

## Intent

After legacy deletion there is only one model, so "V7" branding is noise the owner wants gone. Remove V7/v7 from all user-facing surfaces: `--help` output, command output strings, skill prose, README, docs. Deep identifiers (on-disk schema strings like `tusker.task/v7`, package names like `internal/v7schema`, Go symbol names) stay as-is unless a rename is purely mechanical and safe; record what was intentionally kept and why as evidence.

## Acceptance

| ID | Outcome | Proof |
|---|---|---|
| A1 | `tusker --help` and every help subpage contain no "V7"/"v7" text. | Inline verification |
| A2 | `skill/SKILL.md` and `skill/references/**` contain no version branding outside historical/migration notes. | Inline verification |
| A3 | A recorded decision lists which deep identifiers were kept versus renamed. | Evidence card |

## Non-goals

- No schema-string migration for existing vault files.
- No package renames beyond mechanical, behavior-preserving ones.
