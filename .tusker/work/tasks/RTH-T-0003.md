## Intent
Stopping, restarting or retiring a run by task ID fails with "matches multiple
projects; supply the project" whenever another project has a task with the
same ID, even when the command runs inside one project's folder. When the
current folder belongs to a registered project with a matching run, use it.

## Failure and edge cases
- Outside any registered project the ambiguity error stays as today.
- An explicit project flag always wins.
