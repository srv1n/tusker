# WUX-T-0014 · Add bounded Documents discovery and metadata helpers

## Intent

Agents can route to the smallest useful documentation context and safely validate or scaffold metadata through the existing docs command family.

## Acceptance

| ID | Outcome | Proof |
|---|---|---|
| A1 | A bounded browse command returns one directory level of real folders and direct managed files with stable human and JSON output, truncation metadata, discovery fields, and path-containment errors. | See mapped verification. |
| A2 | Exact document and section reads plus backlink inspection use the shared parser/resolver, expose supersession and provenance truthfully, and never dump unrelated documents. | See mapped verification. |
| A3 | A compact check command reports named header, duplicate-subject, supersession, and managed-link defects with repair guidance; scaffold assistance is non-destructive, validated, atomic, and never manufactures verification or rationale. | See mapped verification. |
| A4 | CLI help and current documentation describe shipped commands, read-only behavior, JSON shapes, bounds, and unsupported cases; focused tests prove deterministic output and zero writes for reads. | See mapped verification. |
