# SRV-T-0028 · Native folder picker for Serve project registration

## Intent

Replace the error-prone manual-only path entry in the Serve sidebar's Add
project form with native folder selection when the UI is running inside the
Tusker macOS shell. The picker must return the selected directory's absolute
path to the existing form state, so registration continues through the same
validated `POST /api/projects` contract.

The web UI also runs in ordinary browsers. Browser mode must stay honest: do
not upload a folder or infer an absolute path from browser-only file handles.
Keep manual entry available there and explain that Browse is available in the
Tusker desktop shell when no native picker bridge is present.

## Acceptance

| ID | Outcome | Proof |
|---|---|---|
| A1 | The Add project form has Browse controls for repository path and optional vault path. In the macOS shell, each control opens a folder-only native `NSOpenPanel`; choosing a folder fills only its corresponding field, while cancel leaves the existing value unchanged. | `command: cd internal/serve/ui && bun test && cd ../../.. && swift test --package-path apps/mac/TuskerBar` |
| A2 | The native bridge is origin-scoped and returns a real absolute directory path to the web form without changing the existing registration payload or validation rules. Manual typing remains possible; browser mode does not claim to derive an absolute path from a browser file selection and gives an actionable explanation when Browse is unavailable. | `command: cd internal/serve/ui && bun run typecheck && cd ../../.. && go test ./cmd/tusker -run 'TestServeProjectRegistration' -count=1` |
| A3 | Focused tests cover the UI controls/bridge contract, selection and cancellation behavior, and native picker configuration/response handling; the existing project-registration backend tests remain green. | `command: make test` |

## Non-goals

- Do not change the `POST /api/projects` request shape or loosen repository/vault
  path validation.
- Do not implement browser folder uploads, directory crawling, or a new server
  endpoint for file selection.
- Do not remove manual path entry; it remains the fallback outside the native
  macOS shell.
