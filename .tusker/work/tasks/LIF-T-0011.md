# LIF-T-0011 · Run end-to-end delivery and interruption dogfood matrix

## Intent

Prove the complete lifecycle in a disposable local fixture project after every implementation slice lands. Exercise native registration, shared-project launch, manual and daemon ownership races, Codex and Claude session identity/resume, successful delivery, failure, abrupt termination, reclaim, truthful UI projection, and token-control disablement. Fix defects found; do not replace failures with waivers or human gates.

## Acceptance

| ID | Outcome | Proof |
|---|---|---|
| A1 | Native project registration stores the selected repository, leaves auto-spawn off by default, and launches shared-mode Codex/Claude runs from that exact registered path. | automated_test |
| A2 | A deterministic race matrix proves exactly one winner for daemon-vs-manual, Codex-vs-Claude, and two-manual claims of one task; shared project concurrency blocks a second modifying task at the default limit. | automated_test |
| A3 | Success submits a real fixture diff plus acceptance-mapped verification to review; an exit-zero/no-diff attempt is rejected as undelivered. | automated_test |
| A4 | Forced failure and killed-process scenarios become failed/interrupted, leave inspectable history, release capacity after policy permits, and support safe reclaim/redrive. | automated_test |
| A5 | Run/session inspector exposes correct project/workspace/session/resume/authorization/delivery information, and the board shows live work separately from historical attempts throughout transitions. | automated_test |
| A6 | Malformed and cumulative usage telemetry neither blocks dispatch nor appears as authoritative aggregate usage. | automated_test |
| A7 | Full Go, Serve UI, skill-doctor, and macOS-shell test/build suites pass after the dogfood matrix. | broad_test |

## Non-goals

- Do not test against the operator's real product repositories or consume live task contracts.
- Do not add human gates or waive failing scenarios.
- Do not declare success from session creation alone; require the expected diff and verification.
- Do not re-enable token enforcement as part of this epic.
