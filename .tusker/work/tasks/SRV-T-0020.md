# SRV-T-0020 · Needs inbox review cards separate human summary from proof detail

## Intent

Make the Needs me review cards read like an operator inbox instead of a raw acceptance/proof dump. The card should tell the human what decision is needed, then expose proof detail as supporting evidence.

## Acceptance

| ID | Outcome | Proof |
|---|---|---|
| A1 | Review cards show a concise human-facing summary of the task and decision before listing proof rows. | focused_test |
| A2 | Acceptance/proof rows remain available with pass/fail state, but raw developer-style wording is no longer the main card body. | focused_test |
| A3 | Failed-run items still show the failure reason and the next operator action clearly. | broad_test |

## Non-goals

- No new task detail page beyond linking to existing task detail surfaces.
- No change to proof semantics or close policy.
- No removal of acceptance/proof data from the API.
