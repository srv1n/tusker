# OPS-T-0009 · Release gate builds and tests the embedded Serve UI

## Intent

The shipped Go binary embeds `internal/serve/ui/dist`, but the central and
release gates currently run only Go checks. A tag can therefore pass CI while
embedding stale frontend assets. Make the Serve UI part of the release-candidate
gate: install the pinned Bun dependency graph, typecheck, test, and build it
before the Go binary is compiled locally or in GitHub Actions.

## Acceptance

| ID | Outcome | Proof |
|---|---|---|
| A1 | `make check` installs the locked UI dependencies and runs UI typecheck, tests, and production build before compiling the Go binary. A UI failure fails the gate. | focused_test |
| A2 | CI and tag-release jobs install the pinned Bun version and use the same `make check` gate, so release artifacts embed assets built from the tagged source. | focused_test |
| A3 | The complete UI and Go release-candidate gate passes from the current checkout. | broad_test |

## Non-goals

- No deployment, signing, notarization, or release-tag creation.
- No frontend feature changes.
