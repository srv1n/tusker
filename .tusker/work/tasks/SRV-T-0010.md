# SRV-T-0010 · Unify the editor: click-to-edit prose in the task view, retire the raw textarea and the markdown detour

## Intent

Operator friction (2026-07-06): editing a task today is an awkward detour. You land on the structured task view (`TaskContract.tsx`), but real body editing lives on a *different route* — the "Open markdown" button (`TaskContract.tsx:69-77`) links to `DocReader`, which opens read-only, and only then does an "Edit" button (`DocReader.tsx:126`) flip the same TipTap surface to editable. The button says "markdown" but `DocReader` is not raw markdown — it is the same WYSIWYG TipTap render (`editor/DocEditor.tsx`, `editable` toggled), so the label actively misleads and makes editing feel like "drop into markdown first." Meanwhile TaskContract's own inline edit is a bare monospace `<textarea>` (`EditableProse`, `TaskContract.tsx:348-420`) — the "garbage" edit state — already flagged unfinished at `TaskContract.tsx:347`: `TODO(api): TipTap markdown surface (shared with the doc reader)`.

Fix — one surface, no ceremony. The good editor (`editor/DocEditor.tsx`, TipTap + tiptap-markdown, already built) becomes the prose surface *in the task view*:
- Replace `EditableProse` with `DocEditor`; delete the raw textarea path.
- Fold `DocReader`'s edit capability into TaskContract so there is no route hop to edit. The read view is already a TipTap instance with `editable=false`, so clicking into a prose block flips `editable` on — cursor in, type.
- Demote "Open markdown" to a read-only "View source" escape hatch (raw `.md`), not the path to editing. The task view becomes the single home for reading and editing.

Scope seam: this task delivers the unified click-to-edit surface and removes the detour and the textarea. It does **not** change the save model — editing still commits through the existing `useDocEditor` path (`editor.ts`) with CAS/validation intact, as an interim. SRV-T-0011 replaces that trigger with ambient autosave and removes any explicit save affordance. Sequencing this way keeps each task shippable and low-risk.
