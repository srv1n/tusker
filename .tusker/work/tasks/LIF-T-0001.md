# LIF-T-0001 · Disable token budgets, circuit breakers, and authoritative usage UI

## Intent

Remove unreliable token accounting from Tusker's control plane until usage can be measured without summing cumulative runner snapshots. Dispatch, retry, and operator status must continue regardless of missing, malformed, or oversized token telemetry. Preserve historical usage rows for later forensic work, but stop presenting aggregate totals as authoritative or allowing them to open a budget circuit.

## Acceptance

| ID | Outcome | Proof |
|---|---|---|
| A1 | Daily/project token budgets and token circuit breakers are disabled by default and cannot block daemon or manual dispatch. Existing enabled configuration migrates to the disabled behavior without deleting task, run, attempt, or raw usage history. | focused_test |
| A2 | Serve and CLI operator surfaces omit authoritative aggregate token totals and clearly avoid treating diagnostic usage as billable or exact. No stale circuit-open banner remains after upgrade. | focused_test |
| A3 | Runner result normalization remains compatible with optional usage payloads, but missing, malformed, nested cumulative, or extremely large counters cannot fail or pause an otherwise valid run. | focused_test |
| A4 | Focused and broad regression suites pass with token telemetry absent and with legacy usage rows present. | broad_test |

## Non-goals

- Do not redesign accurate billing or incremental token attribution in this task.
- Do not delete historical usage or attempt records.
- Do not remove non-token safety controls such as disk, process, concurrency, or retry guards.
