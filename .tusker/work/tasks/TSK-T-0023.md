## Problem and outcome
External findings: C1.
queueWorkerLifecycle writes one .tusker-worker-lifecycle.json per workspace; consumeWorkerLifecycleRequest validates the embedded request but does not bind it to the run being reconciled. The removed shared-checkout serial guard permits collisions. Restore serial admission for shared-checkout waves and check project, record, attempt and lease generation against the consuming run before applying/removing a request. Preserve isolated workspace concurrency. Per-attempt storage and shared parallelism are explicitly deferred; do not build that larger feature.
