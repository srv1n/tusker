# ORC-T-0043 · Replace reviewer prose and merge choreography with typed results

## Intent

An independent reviewer emits one attempt-bound pass, changes-requested, or blocked result that the deterministic control plane can validate and react to.

## Acceptance

| ID | Outcome | Proof |
|---|---|---|
| A1 | Review submit persists one compare-and-swap result bound to task and work revision, implementation SHA, reviewer attempt and actor, runner profile, acceptance coverage, proof and gate fingerprints, verdict, bounded summary, findings, and evidence references. | See mapped verification. |
| A2 | Pass requires complete acceptance coverage and currently satisfied objective proof and gates, changes_requested requires at least one actionable finding, and blocked requires a typed machine, infrastructure, or genuine human blocker. | See mapped verification. |
| A3 | Stale task, source, attempt, proof, gate, or reviewer authority is refused and repeated submission of the exact result is idempotent without overwriting a conflicting verdict. | See mapped verification. |
| A4 | Reviewer prompts and skills restrict the reviewer to read-only inspection and typed result submission and remove instructions to merge, land, close, move refs, or edit implementation files. | See mapped verification. |
| A5 | Reviewer prose, an unmarked verification row, and process exit are never acceptance; exit without one valid result leaves review open and follows bounded retry or park policy. | See mapped verification. |
| A6 | Existing generated reviewer findings remain readable and migrate into the structured projection without losing task or attempt attribution. | See mapped verification. |
