# FAC-T-0012 · Replay a failed attempt for review without spending new model calls

## Intent

When an attempt fails and someone needs to judge what went wrong, they should be
able to replay that attempt from its recorded trail without spending any new
model calls. The replay reads what already happened; it does not go back and ask
the model again. That keeps adjudication cheap and honest — the reviewer sees the
real recorded steps, not a fresh, possibly different run.

Recordings of the run's edges and a replay already exist; this task guarantees
that a review replay makes zero fresh model calls and says so plainly, and that
it reports clearly when the recording is missing pieces instead of quietly
reaching for the model.

Done looks like: replaying a recorded failed attempt reproduces its steps for a
reviewer, reports that it made zero new model calls, and clearly flags an
incomplete recording rather than silently calling the model.

## Acceptance

| ID | Outcome | Proof |
|---|---|---|
| A1 | Replaying a recorded failed attempt reproduces its recorded steps for a reviewer. | Inline verification |
| A2 | The replay reports that it made zero new model calls. | Inline verification |
| A3 | An incomplete recording is reported clearly instead of silently calling the model. | Inline verification |

## Non-goals

- No re-execution against the live model under any flag in this adjudication mode.
- No repair of an incomplete recording; it is reported, not reconstructed.
- No new recording format; this reads the trail already captured.
- No UI surface for the replay here; it is a command-line adjudication path.
