# RUN-T-0017 · Re-entry trial: prove the hardened daemon on the real machine before it resumes as executor

## Intent

Standing decision (2026-07-06): the daemon stays down as executor until hardened AND proven live. The e2e suite proves semantics in fixture repos; this task proves them on the operator's actual machine, with real codex runners and real (small) spend, under a deliberately hostile script. It is the gate between "the code says so" and "we bet the factory on it." Passing this task is what authorizes turning the daemon back on at cap 5.

Trial script (run against this repo's vault, cap 2, low-risk cohort only — pick 2–3 small real tasks, p2/low, so the spend is bounded and the output is still useful):

1. **Cold start**: `tusker daemon run` (or launchd-managed if RUN-T-0015 landed) sweeps all legacy ghost run records within one tick; sentinel green; UI honest.
2. **Kill-9 mid-run**: SIGKILL the daemon while both runs are mid-attempt. Verify: wrappers survive (RUN-T-0013), keep heartbeating; restarted daemon adopts both verified-alive without interrupting them.
3. **Review-flip under a live run**: move one task to review while its run is active. Verify: the run halts via the heartbeat stop-signal within one beat; no re-dispatch; no continuation loop (the incident scenario, live).
4. **Budget trip**: set a deliberately low per-attempt budget on one task; verify the run is killed at the ceiling, the attempt records `budget_exceeded`, and caps count it.
5. **Poison park**: force no-progress continuations (task contract that cannot progress); verify park at cap with `parked_no_progress`, cooldown honored, `tusker redrive` restores dispatchability once.
6. **Circuit**: inject a sentinel violation (stale lease by hand in the store); verify circuit-open, no dispatch, `daemon resume` refuses until fixed, then clears.
7. **Drain stop**: `tusker daemon stop --drain` completes cleanly; plain `stop` leaves wrappers for adoption (verify by restarting).

Every step's observed result is recorded as evidence cards (command + expected + observed); deviations file bugs, and the trial repeats after fixes until a clean full pass. On the clean pass: raise `max_active_runs` back to 5 and record the authorization in this task's closeout.
