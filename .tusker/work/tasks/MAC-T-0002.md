# MAC-T-0002 · Global hotkey, settings window, launch-at-login (SMAppService)

## Intent

Make TuskerBar summonable and configurable. Builds on the scaffold (MAC-T-0006) and panel (MAC-T-0001) in `apps/mac/TuskerBar/`.

- Global hotkey via the `KeyboardShortcuts` SwiftPM package (sindresorhus/KeyboardShortcuts — the standard for user-configurable global shortcuts; do not hand-roll Carbon event taps). Default binding ⌥⌘T. Pressing it toggles the panel from any app, including over full-screen apps.
- Settings window (SwiftUI `Settings`/`NSHostingController`, opened from the status item menu, standard ⌘, shortcut):
  - Hotkey recorder (`KeyboardShortcuts.Recorder`).
  - Base URL override, default `http://127.0.0.1:7420`, persisted in `UserDefaults`; the panel webview and "Open Tusker" menu item must both respect it (feed through one `AppConfig` type, not scattered reads). Validate it parses as an http(s) URL; reject others.
  - "Launch at login" toggle via `SMAppService.mainApp` (macOS 13+ API) with its actual registration state reflected on open (registration can be revoked in System Settings behind the app's back).
  - "Show Dock icon" toggle: switches `NSApp.setActivationPolicy` between `.accessory` and `.regular` live, persisted across launches.
- Status item menu gains "Settings…" and shows the current hotkey next to a "Toggle panel" item.

## Acceptance

## Non-goals

- No notification preferences (MAC-T-0003 adds its own section).
- No multiple-profile/base-URL list; one URL is enough.
- No daemon lifecycle management (start/stop buttons) — hint text only, as shipped in MAC-T-0001.
