# LIF-T-0007 · Persist runner session identity and resumable workspace metadata

## Intent

Persist enough normalized identity to locate, inspect, and resume every Codex or Claude execution without searching harness-private directories. Keep registered project path and physical workspace distinct, and attach runner session identity as soon as the harness supplies it.

## Acceptance

| ID | Outcome | Proof |
|---|---|---|
| A1 | Run records persist project id, registered repository path, physical workspace, workspace mode, runner kind, runner session id, process identity when available, branch/HEAD context, and start/heartbeat/end timestamps. | focused_test |
| A2 | Codex and Claude event parsers attach one stable top-level session id without mistaking subagent ids, message ids, UUIDs, or task-notification ids for separate operator sessions. | focused_test |
| A3 | The API/CLI returns runner-specific resume capability and a correctly escaped copyable resume command when supported; unsupported/expired sessions report a reason instead of a fabricated command. | focused_test |
| A4 | Sessions created in opt-in worktrees remain grouped under the registered project while exposing the physical path. Shared-mode sessions use the exact registered repository cwd. | focused_test |
| A5 | Reconcile preserves session metadata across daemon restart and marks missing workspaces/processes accurately without deleting history. | broad_test |

## Non-goals

- Do not parse private transcript contents to determine whether code was delivered.
- Do not use the physical workspace path as the sole project key.
- Do not expose unescaped shell commands containing operator-controlled paths.
