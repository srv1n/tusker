# W-0049 · Process containment

## Intended result

Tusker keeps an inventory of every process it starts, stops checks with their starter, cleans up orphans with one janitor, never repeats a gate across restarts, never leaks processes from its own tests, and shows all of it in the operator UI.

## Shared context

Read the process containment spec first. Locked: only agent sessions may outlive
the daemon; checks end with their starter; one janitor at startup and on poll
cadence, no per-process polling loops; agent sessions are never stopped for running
long or being silent, only flagged; safety stops never depend on a model; never
stop a process whose PID, process group and start time do not all match.
Incident evidence: 2026-10-18, about 54 leaked test runner-wrappers, a watchdog
crash loop every three minutes, and the landing gate rerun on every restart.
