# VSK-T-0002 · Export V7 repo knowledge as a project skill bundle

## Agent capsule

- Essence: Export V7 repo knowledge as a project skill bundle.
- Next action: define acceptance, do the smallest scoped change, and attach concise evidence.
- Read next: this note, then only the code/docs anchors named here.
- Avoid: raw logs, full transcripts, generated indexes, and attachments unless doing evidence forensics.

## Intent
Make project skill export first-class for V7. The exported skill package should represent the repository knowledge base as an agent skill, using V7 `tusker/knowledge/domains/**` as source truth while preserving compatibility with the older V6 export path.

## Acceptance contract

| # | Outcome | Proof required | Docs impact |
|---|---|---|---|
| 1 | `tusker publish skill` or `tusker publish skill --v7` exports a project skill package containing `SKILL.md` and V7 domain canon from `tusker/knowledge/domains/**`. | Temp-repo smoke plus file assertions. | Update CLI docs and skill reference. |
| 2 | Exported skill excludes task records, evidence logs, attempts, generated indexes, raw logs, and private runtime state by default. | Fixture test with forbidden files present. | Document source/publication boundary. |
| 3 | Export chooses V7 source when V7 knowledge exists, or exposes an explicit mode with clear help text during transition. | CLI help test plus export test for V6 and V7 inputs. | Explain V6 compatibility mode. |

## Scope

In:
- V7-aware project skill export.
- Generated project `SKILL.md` that routes to V7 domain indexes and canon.
- Filtering rules for task/evidence/generated/runtime content.
- Backward-compatible behavior for existing V6 project skill exports.

Out:
- Publishing to external package registries.
- Bundling the Tusker operator skill into every project skill package.
- Copying full raw evidence artifacts into the skill.

## Deliverables

- Export implementation and tests.
- Updated help text for `publish skill`.
- Fixture coverage for V7 knowledge domains.
