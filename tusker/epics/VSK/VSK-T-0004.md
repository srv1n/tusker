## Intent
Make the two-skill model explicit everywhere agents and humans will look. The Tusker operator skill teaches work tracking, evidence, gates, close policy, and CLI mechanics. The project knowledge skill is generated per repository and teaches agents how to read and update that repository's canon.

## Acceptance contract

| # | Outcome | Proof required | Docs impact |

| 1 | Operator skill docs explicitly say what belongs in the Tusker skill versus the generated project knowledge skill. | Skill/doc diff review. | Direct update to skill reference and agent recipe. |

| 3 | Docs warn against publishing task bodies, raw logs, evidence bodies, attempts, generated manifests, or agent-only instructions as user docs. | Text review against V7 spec rules. | Update docs publication guidance. |
