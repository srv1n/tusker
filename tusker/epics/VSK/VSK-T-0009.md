# VSK-T-0009 · Make install/update tests and repo install mode hermetic

## Agent capsule

- Essence: Make install/update tests and repo install mode hermetic.
- Next action: define acceptance, do the smallest scoped change, and attach concise evidence.
- Read next: this note, then only the code/docs anchors named here.
- Avoid: raw logs, full transcripts, generated indexes, and attachments unless doing evidence forensics.

## Intent
Prevent installer/update tests and repo-local install modes from touching real user-level skill installs unless the command under test explicitly uses a temp HOME or the user intentionally selected user install behavior.

## Acceptance contract

| # | Outcome | Proof required | Docs impact |
|---|---|---|---|
| 1 | Install/update tests that exercise user skill destinations always set `HOME`/`USERPROFILE` to a temp directory. | Full package test run. | None. |
| 2 | Repo-local install/update tests do not discover or mutate real `~/.agents`, `~/.codex`, or `~/.claude` installs. | Regression test with temp home. | Clarify help only if behavior changes. |
| 3 | `go test ./...` no longer fails on `TestInstallCommandInstallsRepoSkillsWithoutBinary` because of a real user skill directory. | `go test ./...` or documented unrelated-only failure. | None. |

## Symptom

- `go test ./... -count=1 -timeout=180s` attempted to remove or replace `<home>/.agents/skills/tusker` from `TestInstallCommandInstallsRepoSkillsWithoutBinary`.
- The test failed with `unlinkat <home>/.agents/skills/tusker: directory not empty`.

## Reproduction

1. Run `go test ./... -count=1 -timeout=180s` on a machine that already has a user-level Tusker skill installed.
2. Observe `TestInstallCommandInstallsRepoSkillsWithoutBinary`.

Expected:
- Tests use temp HOME fixtures and never touch real user-level skill directories.

Observed:
- The repo install test calls `installCmd(Args{"repo": repo, "no-bin": "true", "quiet": "true"})`.
- `installCmd` starts from `existingUserSkillDestinations()`, so it discovers real user skill directories unless the test overrides HOME.

## Scope

In:
- Make install/update tests hermetic.
- Review whether `tusker install --repo ... --no-bin` should refresh existing user installs by default or require an explicit user flag.
- Update tests/help to match the chosen behavior.

Out:
- Changing embedded skill payload contents.
- Adding platform-specific installer behavior beyond this safety fix.

## Deliverables

- Test isolation fix for install/update command coverage.
- Optional CLI behavior adjustment if repo-local install should not imply user-skill refresh.
- Regression coverage proving no real HOME mutation.

## Verification plan

- `go test ./cmd/tusker -run 'TestInstallCommand|TestUpdateCommand|TestInstallSkillPayload' -count=1`
