# VSK-T-0003 · Validate V7 skill and knowledge conformance

## Agent capsule

- Essence: Validate V7 skill and knowledge conformance.
- Next action: define acceptance, do the smallest scoped change, and attach concise evidence.
- Read next: this note, then only the code/docs anchors named here.
- Avoid: raw logs, full transcripts, generated indexes, and attachments unless doing evidence forensics.

## Intent
Teach `tusker validate` to enforce the V7 skill-shaped knowledge contract. A repository should fail validation when its project skill cannot route agents to canon, when V7 domain records are malformed, or when docs/skill surfaces drift from the V7 spec.

## Acceptance contract

| # | Outcome | Proof required | Docs impact |
|---|---|---|---|
| 1 | Validation checks the presence and schema of the V7 project knowledge skill entrypoint. | Failing and passing fixture tests. | Document validator failures and fixes. |
| 2 | Validation checks V7 domain `INDEX.md` and `CANON.md` records for required routing, source-of-truth, status, and canonical file metadata. | Unit tests over malformed V7 domains. | Update validator reference. |
| 3 | Validation catches project skill exports or repo skill pointers that include forbidden task/evidence/generated/runtime material as source truth. | Fixture test with forbidden paths. | Explain the publication boundary. |
| 4 | Branch policy remains focused on protected state fields and does not block safe documentation/domain knowledge updates from implementation branches. | Branch-policy regression test. | Clarify allowed branch-side updates. |

## Scope

In:
- V7 validation rules for project skill entrypoint and domain canon.
- Human-readable issue codes and hints.
- Tests for missing, malformed, and stale skill/knowledge surfaces.
- Compatibility with existing V6 validation.

Out:
- Semantic verification that every canon statement is correct.
- External link crawling.
- Blocking all docs edits from feature branches.

## Deliverables

- Validator implementation.
- Issue codes and hints.
- Test fixtures for valid and invalid V7 skill/knowledge layouts.
