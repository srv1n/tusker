# VSD-T-0006 · Harden V7 branch policy across all protected state

## Intent

Close branch-safety holes before V7 is trusted by teams. Control mutations must run against the repo root, reject detached or unknown branch state in team mode, and cover every protected V7 object field.

## Acceptance

| ID | Outcome | Proof |
|---|---|---|
| A1 | Branch detection uses `git -C <repo-root> rev-parse --abbrev-ref HEAD` and treats `HEAD`, empty branch, and non-git contexts as errors unless local-only mode is explicit. | unit and fixture tests |
| A2 | `ensureV7ControlMutation` and branch-policy validation reject protected mutations from implementation branches without an explicit approved escape hatch. | branch-policy tests |
| A3 | Protected-field diff checks cover tasks, gates, epics, decisions, evidence acceptance fields, attempt close markers, and proposal application state. | table-driven validator tests |
| A4 | CI runs branch-policy validation for pull requests. | CI workflow evidence |

## Non-goals

- Do not allow detached HEAD as a convenience default.
- Do not treat unknown branch as safe.

## Verification

- Command: `go test ./cmd/tusker -run 'Test.*Branch|Test.*Protected|Test.*ControlMutation' -count=1`
- `tusker validate --branch-policy-only --staged --json`
- `go test ./...`
