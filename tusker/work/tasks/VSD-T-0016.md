# VSD-T-0016 · Prove the V7 daemon path end to end

## Agent capsule

Build the release milestone smoke: clean checkout creates V7 work, daemon claims it, fake runner produces proof, task enters review/close policy. Start with daemon tests and the CLI smoke tests.

## Intent

Make the production path observable end to end. Tusker is not shippable until a clean repo can create a V7 task, show it in the vault, have the daemon claim it, run a fake runner, attach evidence, enter review, and close according to proof policy.

## Scope

In scope:
- A clean-clone or temp-repo V7 orchestration smoke.
- Fake runner path only; live Codex/Claude adapters can stay covered elsewhere.
- Evidence/review/close assertions that prove the lifecycle did not stop at dispatch.

Out of scope:
- UI/browser docs-site checks.
- Real provider authentication or external services.

## Acceptance

| ID | Outcome | Proof |
|---|---|---|
| A1 | A temp repo can `init`, create an epic, create a V7 task, validate, and build dashboards. | automated smoke test |
| A2 | The daemon/fake runner claims a V7 `ready` task without `type: task`, records an attempt/run, and prevents duplicate claim. | daemon integration test |
| A3 | The smoke attaches acceptance-linked evidence and moves the task into review or closes it according to configured proof policy. | automated smoke test |
| A4 | The smoke is wired into CI or `make check` so the production path cannot regress silently. | CI/make evidence |

## Constraints

- Do not depend on live Codex, Claude, network access, or a developer-global state directory.
- Do not treat raw logs as evidence.
- Keep the fixture small enough to run in normal CI.

## Escalate if

- The daemon cannot be tested without touching real user state.
- Proof policy cannot close or request review deterministically in a temp repo.

## Deliverables

- One end-to-end V7 orchestration smoke test.
- CI or `make check` integration.
- Evidence that duplicate claims are prevented in the tested path.

## Non-goals

- Do not broaden this into full runner-adapter coverage.
- Do not implement docs-site publishing.
