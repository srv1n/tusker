# VSD-T-0021 · Lock down publish/export and security trust boundaries

## Agent capsule

Make export/publish safe by default and document the trust model. Start with docs export, generated site inputs, runtime/raw artifact paths, and validation.

## Intent

Prevent Tusker from accidentally publishing agent-private or runtime material. The production model can execute commands and collect evidence, so export defaults must exclude raw logs, events, attempts, local runtime, and generated internals unless deliberately included.

## Scope

In scope:
- Trust-boundary documentation for workflow hooks, runner commands, raw logs, and local repos.
- Export/site validation that excludes runtime and raw artifacts by default.
- Symlink-escape tests for cleanup/export paths that traverse repository content.
- Redaction requirements for evidence/log excerpts.

Out of scope:
- Building a public docs site feature from scratch.
- Sanitizing arbitrary pasted third-party logs retroactively.

## Acceptance

| ID | Outcome | Proof |
|---|---|---|
| A1 | Docs/site export excludes `.tusker-runtime`, `.tusker-local`, raw runner logs, event JSON, attempts, generated indexes, and task/evidence internals unless explicitly opted in. | export validation test |
| A2 | Redaction rules for log excerpts/evidence are documented and enforced where publishable artifacts are selected. | validation or docs test |
| A3 | Cleanup/export code cannot follow symlinks out of the intended workspace when deleting or collecting artifacts. | symlink-escape test |
| A4 | User-facing docs state the trusted-local-repository model and do not imply safe execution for untrusted repos. | docs diff/review |

## Constraints

- Do not publish task records, evidence logs, attempts, runner transcripts, generated indexes, or agent-only instructions as human docs.
- Keep Obsidian dashboards as local projections unless a publish path explicitly transforms them.
- Prefer allowlists for publication surfaces.

## Escalate if

- Existing site build depends on generated private/runtime artifacts.
- A retained docs feature cannot be made safe without a product decision.

## Deliverables

- Export allowlist or validation rule.
- Trust-boundary docs.
- Symlink and private-artifact regression tests.

## Non-goals

- Do not solve untrusted-code sandboxing.
- Do not revive legacy Diataxis publication semantics as canonical V7 behavior.
