# VSD-T-0013 · Set generated-index ownership policy for V7 dashboards

## Intent

Decide and enforce which V7 generated dashboard/index artifacts are committed. Generated files must either be validated as committed projections or ignored and rebuilt locally; vague ownership creates merge noise.

## Acceptance

| ID | Outcome | Proof |
|---|---|---|
| A1 | Policy chooses one default: commit human-facing dashboard/Bases markdown and ignore low-level JSON indexes unless required by Obsidian. | documented decision |
| A2 | `.gitignore`, dashboard builder output paths, and validation match the chosen policy. | automated tests |
| A3 | If committed projections remain, validation detects stale generated artifacts and tells the operator how to rebuild. | stale fixture test |
| A4 | `tusker dashboard build` is deterministic for committed artifacts. | repeat-build diff test |

## Non-goals

- Do not hand-edit generated indexes.
- Do not preserve JSON churn without a consumer requirement.

## Verification

- Command: `go test ./cmd/tusker -run 'Test.*Dashboard|Test.*Generated|Test.*Index' -count=1`
- `tusker dashboard build --quiet`
- `git diff -- tusker/_generated tusker/dashboards`
