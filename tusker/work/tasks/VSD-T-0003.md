# VSD-T-0003 · Remove Diataxis from canonical V7 knowledge

## Intent

Remove Diataxis from the canonical V7 knowledge model. Tusker may later publish human docs, but canonical project knowledge must be skills-style operational knowledge for agents and maintainers.

## Acceptance

| ID | Outcome | Proof |
|---|---|---|
| A1 | V7 knowledge policy allows only domain index, canon, runbook, decision, invariant, interface, glossary, and source node kinds. | validator fixture tests |
| A2 | V7 canonical knowledge validation rejects `tutorial`, `how-to`, `explanation`, `reference`, `diataxis`, and docs-map modes. | negative validator tests |
| A3 | V7 packets, briefs, skill generation, and knowledge routing do not read `docs-map.yaml` or canon manifests as canonical truth. | CLI smoke tests and `rg` guardrail |
| A4 | Optional docs publishing, if retained, is clearly quarantined under legacy or site-specific commands. | help snapshot and command routing tests |

- Do not rename every historical file unless it is in the V7 canonical path.
