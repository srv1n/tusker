# VSD-T-0008 · Deepen V7 close validation to prove acceptance

## Intent

Make `done` mean the accepted outcome is proved. Closing a task must validate acceptance coverage, unresolved gates, actor policy, durable evidence, and explicit waivers.

## Acceptance

| ID | Outcome | Proof |
|---|---|---|
| A1 | Every acceptance ID requires accepted evidence coverage or an explicit waiver with actor, timestamp, and reason. | close-policy tests |
| A2 | Open blocking gates, unresolved dependencies, unresolved rework blockers, and missing risk gates prevent close. | negative close tests |
| A3 | Close validation enforces risk policy for human/reviewer actors and screenshot review requirements. | policy fixture tests |
| A4 | Evidence artifacts referenced by accepted proof must be durable unless explicitly external. | validation tests |
| A5 | Legacy or migrated records are not silently treated as V7-compliant acceptance; if retained, they are visibly historical or legacy-only. | migration/quarantine test |

## Non-goals

- Do not preserve old done semantics as V7 close semantics.
- Do not require acceptance proof from generated packets.
