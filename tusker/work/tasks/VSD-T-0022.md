# VSD-T-0022 · Dogfood V7 project knowledge in this repo

## Intent

Dogfood the V7 project-knowledge model in this repository. The product now routes
V7 packets to `tusker/knowledge/domains/**`, but this repo still has a V6-shaped
project skill and domain corpus:

- `tusker/SKILL.md` declares `schema: tusker.project-skill/v6`.
- `tusker domain list --v7` returns no domains.
- Current domain canon lives under `tusker/domains/**`.
- `tusker packet VSD-T-0010 --for agent` routes to
  `knowledge/domains/knowledge/INDEX.md` and reports missing domain context.

That makes the canonical routing story true in new fixtures but false in the
dogfood repo. Fix the repo-local knowledge layout so agents using real Tusker
tasks land on real V7 domain canon.
