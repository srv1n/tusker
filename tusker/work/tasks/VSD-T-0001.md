# VSD-T-0001 · Restore a green fresh-clone build and CI baseline

## Intent

Make the repository buildable from a fresh clone before any further V7 product work. Product decisions are moot while module metadata, dependencies, and embedded skill assets are missing or inconsistent.

## Acceptance

| ID | Outcome | Proof |
|---|---|---|
| A1 | Fresh clone test setup has `go.mod`, `go.sum`, and all external dependencies needed for `go test ./...` to compile. | `go test ./...` evidence record |
| A2 | `skill/bundle.go` embeds only committed paths, or the missing `SKILL.md`, `LICENSE`, `references`, `docs`, `agents`, and `assets` paths are restored intentionally. | automated test plus file inventory |
| A3 | CI runs the fresh-clone baseline: `go test ./...`, `go vet ./...`, gofmt check, and Tusker validation. | CI workflow diff and local automated test |
| A4 | Build failures from missing dependencies or embedded assets cannot recur silently. | failing fixture or CI smoke coverage |

## Non-goals

- Do not change V7 product semantics in this task.
- Do not preserve obsolete docs-publishing assets just to satisfy an embed path; restore only what is intentionally shipped.

## Verification

- Command: `go test ./...`
- `go vet ./...`
- `gofmt` check over tracked Go files
- `tusker validate --branch-policy --json`
