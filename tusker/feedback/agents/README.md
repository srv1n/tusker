# Agent Feedback

Use this folder for concise, actionable feedback about Tusker or repo workflow friction.

Create one Markdown file per meaningful work turn:

`YYYY-MM-DD-<agent-or-tool>-<short-topic>.md`

Keep each note under 10 lines:

- Context:
- Friction:
- Product idea:
- Impact:
- Related task or command:

Do not paste transcripts, logs, diffs, secrets, or raw tool output. Skip the note when there is no useful signal.
