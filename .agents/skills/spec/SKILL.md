# Spec handoff

This retained entry point uses the current Tusker authoring procedure.
Read `../tusker/SKILL.md`, then `../tusker/references/SPECS.md` for canonical
specification and decision capture. Before emitting tasks, read
`../tusker/references/TRACK.md` and its required `HANDOFF.md` reference.

Use an available external design method for unresolved product choices.
An already settled specification does not require another interview.
The planner supplies surrounding work, constraints, proof scenarios and
verified architect/origin contacts before handing work to an implementer.
Use configured work/review levels. Creating tasks does not authorize dispatch.
